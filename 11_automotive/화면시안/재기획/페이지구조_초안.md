## 1. 로그인

```text
┌──────────────────────────────────────────────┐
│                                              │
│        ╭──────────────────────────╮          │
│        │ [페이지 제목]             │          │
│        │  제조운영관리 플랫폼        │          │
│        │                          │          │
│        │ ( 아이디            ▾ )   │ ← 누르면 계정 12개 목록
│        │ ( 비밀번호  ●●●●      )   │ ← 계정 고르면 자동으로 채움 (전 계정 0000)
│        │                          │          │
│        │        ( 로그인 )         │          │
│        ╰──────────────────────────╯          │
└──────────────────────────────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 페이지 제목 | "제조운영관리 플랫폼" |
| 아이디 | 누르면 계정 12개가 목록으로 보이고 고를 수 있음 |
| 비밀번호 | 아이디를 고르면 자동으로 채워짐. 모든 계정 비밀번호 0000 |
| 로그인 | 버튼 |

## 2. AI 비서 "이브" (모든 페이지 공통)

### 2.1 이브 아이콘

```text
┌─────────────────────────────────────┐
│                                     │
│                          (문구)  ◯  │  ← 브리핑
│                          (문구)  ◯  │  ← 알림
│                          (문구)  ◯  │  ← 채팅
│                          (문구)  ◯  │  ← 채팅 기록
│                              (이브)⑱│  ← 우측 하단, 알림 쌓이면 숫자
└─────────────────────────────────────┘
```

- 이브 캐릭터는 우측 하단
- 알림이 쌓이면 숫자 표시
- 누르면 위로 4개 펼침: 브리핑 📋 · 알림 🔔 · 채팅 💬 · 채팅 기록 ☰ (문구 + 아이콘)

- [Q3] 숫자에 세는 것: 처리 안 된 알림 전부 / 긴급·주의만
- [Q4] 이브 캐릭터 그림: 지금 앱의 이브 그대로 / 새로

### 2.2 브리핑

```text
┌───────────────────────────────────┐
│                  ╭─────────────╮  │
│                  │[제목]     X │  │
│                  │ ┌─────────┐ │  │
│                  │ │ 내용     │ │  │
│                  │ └─────────┘ │  │
│                  ╰─────────────╯  │
│                            (이브) │
└───────────────────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 제목 | 로그인 계정에 맞는 브리핑 제목 (예: 일일 보고서 브리핑, 교대 시작 브리핑 등) |
| 내용 | 최대한 간단하게. 요약형 브리핑. 꼭 들어갈 핵심만. **내용 정의는 나중에 필요** |

|---|---|---|

| 정비 담당 | ? | ? |
| 반장 | ? | ? |
| 관리자 | ? | ? |

- [Q6] 내용 정의 전까지 지금 앱의 브리핑 내용을 임시로 넣을지, 빈 자리로 둘지

### 2.3 알림

```text
┌──────────────────────────────────────┐
│                 ╭───────────╮        │
│                 │ 알림       │        │
│                 │ ▭▭▭▭▭▭▭▭  │        │
│                 │ ▭▭▭▭▭▭▭▭  │        │
│                 │ [내용] ───┼──┐     │
│                 ╰───────────╯  │     │
│                         (이브) │     │
└────────────────────────────────┼─────┘
                                 ▼  누르면
                ┃ [제목]                │
                ┃ [설명]                │
                ┗ 왼쪽 띠 = 알림 등급 색 (예: 긴급 = 빨강)
```

| 요소 | 내용 |
|---|---|
| 제목 | 알림 제목 (요약·간단) |
| 설명 | 좀 더 구체적인 설명 |
| 왼쪽 색 띠 | 알림 등급에 맞는 색 (예: 긴급 = 빨강) |

- [Q7] 주의·참고 색 (예: 주의 = 주황, 참고 = 회색)
- [Q8] 알림을 누르면: 목록 안에서 펼쳐짐 / 목록 대신 상세가 보임
- [Q9] 상세에 버튼이 있는지 (지침카드 열기, 처리 완료 등)
- [Q10] 문서 알림(보고서 확정 요청 등)도 같은 목록에 섞는지

### 2.4 채팅

```text
╭──────────────╮
│ ◯ 이브 말     │   ← 카톡 채팅 형식
│     내 말 ◯  │
│ ( 입력 )  ▶  │
╰──────────────╯
```

- 카톡 채팅 형식
- 이브의 답변은 LLM 담당 팀원이 구현

- [Q11] 화면은 제가 만들고 답은 지금처럼 규칙 기반 답을 임시로 붙여 둘지, 답 연결 자리만 비워 둘지
- [Q12] LLM 팀원 쪽과 맞출 주소·형식 (지금 앱은 `/api/assistant`)이 정해졌는지

### 2.5 채팅 기록

```text
╭──────────────╮
│ ▭ 날짜·시간·내용 │
│ ▭ 날짜·시간·내용 │
│ ▭ 날짜·시간·내용 │
╰──────────────╯
```

- 한 줄 = 날짜 · 시간 · 내용

- [Q13] 한 줄을 누르면: 그 대화를 채팅 탭에서 다시 엶 / 아무 동작 없음

### 2.6 이브 창 공통

- [Q14] 창이 열리는 자리: 스케치처럼 오른쪽 카드 (3D 위에 떠 있음) — 3D를 덮어도 되는지

## 3. 3D 뷰 + 메인 페이지

```text
┌──────────────────────────────────────────────────────────────┐
│ [≡] [주간] 10:25                         계정: [작업자2]  [☀] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                         3D 라인                               │
│                                                              │
├──────────────────────────┬───────────────────────────────────┤
│ ╭생산현황╮                │ 설비 상세                          │
│ ┌──────┐  OEE 87%        │ [현재 상태] [정지 시간]   [가동률]   │
│ │ 그래프 │  (가동률 …)     │ [최근 알람] [공구수명               │
│ └──────┘  생산: 72/90개   │             T05 ━━━━━━━━  49%      │
│           손실: 약 2개     │             ⋮               ]      │
│ ────────────────────     │                                   │
│ 작업지시 진행           ▕│                                   │
│ ▭▭▭▭▭▭▭▭▭▭▭▭           ▕│                            (이브) │
│ ▭▭▭▭▭▭▭▭▭▭▭▭           ▕│                                   │
└──────────────────────────┴───────────────────────────────────┘
```

| 영역 | 내용 (스케치) |
|---|---|
| 상단 바 | 메뉴 ≡ · [주간] · 시각 10:25 · 계정: [작업자2] · ☀ |
| 본문 | 3D 라인 |
| 왼쪽 아래 — 생산현황 | 시간대별 그래프, OEE (가동률 …), 생산 72/90개, 손실 약 2개 |
| 왼쪽 아래 — 작업지시 진행 | 목록 + 스크롤 |
| 오른쪽 아래 — 설비 상세 | 현재 상태 · 정지 시간 · 가동률 · 최근 알람 · 공구 수명(T05 막대 49% …) 카드 |

- 페이지 구성은 로그인 계정에 따라 달라야 함. **기본 구조는 위(좌측 구조)** 이고, 계정별 페이지 구조 정의가 필요함

- [Q16] ☀ 아이콘이 무엇인지 (화면 설정 / 밝기 / 다른 것)
- [Q17] "계정: 작업자2"를 누르면: 로그아웃 / 계정 바꾸기 / 동작 없음
- [Q18] 상단 바에 날짜(10/1)는 없어도 되는지. 시연 ×10 표시와 [시연 ▾] 조작판은 어디에 두는지 (시연에 꼭 필요함)
- [Q19] 방금 만든 Claude Design 시안의 하단(윗줄 지표 7칸 + 아래 3칸)과 이 스케치 중 어느 쪽이 기준인지. 스케치 기준이면 병목·재공·예측 칸은 빼는지
- [Q20] 설비 상세 카드 5개의 내용
  - 현재 상태: 상태 + 몇 분째 (예: 가공 · 31분째)?
  - 정지 시간: 오늘 정지 분?
  - 가동률: 그 설비의 이번 교대 가동률?
  - 최근 알람: 가장 최근 알람 1건 / 여러 건? 누르면 지침카드?
  - 공구 수명: OP-30 설비만 공구가 있음. 다른 설비를 고르면 이 칸을 숨기는지
- [Q21] 설비 상세에 처음 보이는 설비 (지금은 반장 = 병목 설비, 작업자 = 담당 공정)
- [Q22] 하단 아래 범례 줄(가공·대기·고장 …)을 남기는지
- [Q23] 계정별로 무엇이 달라지는지 — 아래 표를 채워 주시면 그대로 만듦

## 5. 메뉴 탭 (각각 별도 페이지)

스케치에 적힌 것:

- 지침카드
- 문서함 (일일 보고서 · 교대 보고서 · 작업기록서 ……)
- 로트 추적
- 사내 문서 보기
- ⋮ (탭에 추가할 페이지도 정의 필요)

각 페이지 구조도 정의 필요.

- [Q27] 메뉴에 더 넣을 페이지. 지금 앱에 있는 것 중 후보: 다시 보기, 정지 사유, 검사 기록, 재고, 공구 수명, 예방 정비, 설정, 2D 배치도, 현장 보기
