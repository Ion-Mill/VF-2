## 2. AI 비서 이브

### 2.1 이브 아이콘 [확정]

```text
                                 브리핑   📋
                                 알림     🔔
                                 채팅     💬
                                 채팅 기록 ☰
                                     (이브)⑱  ← 처리 안 된 알림 전부의 수 (Q3)
```

- 이브 그림은 지금 앱 그대로 (Q4)

### 2.2 이브 창 (모든 탭 공통) [확정]

```text
╭───────────────────────────────────╮
│ [브리핑] [알림] [채팅] [채팅 기록]  X │  ← 탭 목록: 누르면 바로 그 창으로 (Q6 추가 요청, Q15)
├───────────────────────────────────┤
│  (탭 내용)                          │
╰───────────────────────────────────╯
```

- 오른쪽에 카드로 열리고 **3D를 덮어도 됨** (Q14)

### 2.3 브리핑 탭 (N1 추천 제목 확정)

```text
│ [교대 시작 브리핑 · 10/1 주간]       │ ← 제목 = 그 계정에 브리핑할 내용 (Q5)
│ ┌───────────────────────────────┐ │
│ │ • 핵심 1줄                      │ │ ← 지금 앱의 브리핑 내용 임시로 (Q6)
│ │ • 핵심 1줄                      │ │
│ └───────────────────────────────┘ │
```

[추천] 계정별 브리핑 제목 → **[N1]**

| 계정 | 제목 (추천) | 임시 내용 (지금 앱) |
|---|---|---|
| 작업자 | 교대 시작 브리핑 · 내 공정 | 요약 5줄 (잠금·표지, 지난 교대 양품, 내 공정 알람, 공구, 총 목표·정비) |
| 보전 담당 | 교대 시작 브리핑 · 정비 | 전체형 중 알람·정비·공구·재고 부족 |
| 반장 | 교대 시작 브리핑 | 전체형 (지난 교대 생산·문제·인계·오늘 할 일) |
| 공장 관리자 | 일일 보고서 브리핑 | 어제 하루 생산·손실·문제 요약 |

### 2.4 알림 탭 [확정]

```text
│ ┃ ⚠ VF2-01 충돌 의심 정지      10:20 │ ← 왼쪽 띠: 긴급 빨강 · 주의 주황 · 참고 회색 (Q7)
│ ┃ ▲ T05 공구 수명 90%          09:58 │
│ ┃ ⓘ 교대 보고서 확정 요청        17:00 │ ← 문서 알림도 섞음 (Q10)
         │ 누르면 목록 대신 상세 (Q8)
         ▼
│ ← 목록                              │
│ ┃ ⚠ VF2-01 충돌 의심 정지            │ 제목 (요약)
│ ┃ 108 → 994 → 992 연쇄 알람 뒤 정지. │ 설명 (구체적)
│ ┃ 보전 담당 호출 · LOT-2610-003-1     │
│ [지침카드 열기]   [처리 완료]          │ ← 버튼 (Q9)
```

## 3. 메인 (3D 뷰 + 하단) ✎

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [≡] [주간] 10/1 10:25                 계정: [작업자 2 ▾] [시연] [⚙]  │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                    3D 라인   (2D 배치도 전환은 여기 안)               │
│                                                                      │
├───────────────────────────────────┬──────────────────────────────────┤
│ 생산현황 (왼쪽 전부)                 │ 작업지시 진행 (오른쪽)              │
│ ┌──────────────┐  OEE 87%         │ ▭ PO-2609-130  ━━━░  22/40 생산중 ▕│
│ │  시간대별 그래프 │  가동률 76%       │ ▭ PO-2609-131  ━░░░   8/50 대기  ▕│
│ │               │  성능   95%       │ ▭ PO-2609-127  ━━━━  60/60 완료  ▕│
│ └──────────────┘  양품률 100%      │ ▭ …                             ▕│
│                   생산 72 / 90개    │                                  │
│                   손실 약 2개       │                           (이브) │
└───────────────────────────────────┴──────────────────────────────────┘
│ 범례 …                                                               │
```

| 요소 | 내용 |
|---|---|
| 왼쪽 위 | [≡ 메뉴] [주간] [날짜] [시각] |
| 오른쪽 위 | 계정: [이름 ▾] → 12개 목록, 고르면 비밀번호 없이 바로 바뀜 (N6) · [시연] 카드 · [⚙ 화면 설정] 카드 (둘 다 버튼 바로 아래 작은 카드, N8) |
| 하단 왼쪽 | **생산현황 전부** — 그래프 · OEE(가동률·성능·양품률) · 생산 n / 90 · 손실 |
| 하단 오른쪽 | **작업지시 진행** (이전 왼쪽 아래에서 옮김) |
| 없앰 | 이전 오른쪽의 **설비 상세** (현재 상태·정지 시간·가동률·최근 알람·공구 수명 카드) → **[N9]** |

### 3.1 계정별 메인 구성 ✎ → **[N10]**

왼쪽은 모든 계정이 위의 생산현황. 오른쪽은 v2 추천을 따르되, 설비 상세 카드가 없어졌으니 아래처럼 읽었다.

| 계정 | 하단 왼쪽 | 하단 오른쪽 (제가 읽은 것) | 3D 처음 |
|---|---|---|---|
| 작업자 | 생산현황 | 작업지시 진행 — **내 공정에 있는 작업지시만** | 내 공정으로 확대 |
| 보전 담당 | 생산현황 | **정비 현황** — 처리 안 된 고장 알람 · 오늘 정지(설비별 막대) · 예방 정비 기한 임박 | 공장 전체 |
| 반장 | 생산현황 | 작업지시 진행 (전체) | 공장 전체 |
| 공장 관리자 | 생산현황 (+ 하루 목표 180 대비 한 줄) | 작업지시 진행 — **납기 위험을 맨 위로** | 공장 전체 |

- 작업자 첫 화면도 메인 (N7)

- 카테고리 목록은 왼쪽 세로 [추천]. 위쪽 가로 탭이 좋으면 말씀해 주세요
- 문서 안의 [수정 이력] 버튼은 남기고, 누르면 문서함 › 수정 이력으로 그 문서가 골라진 채 열림 [추천]
- 지침카드·작업지시서 안의 출처 글씨를 누르면 사내 문서 **팝업 창** (N5)
- [+ 사후 기록] = 설비·시각을 골라 사후 기록을 엶 (작업자·보전만, 2026-10-24). 사후 기록은 간이 작업기록 카테고리에 [사후] 꼬리표로

#### 문서함 › 간이 작업기록 · 사후 (2026-10-24)

급해서 플랫폼보다 먼저 한 일을 **지난 시각으로** 적는다. 같은 간이 작업기록(`MR-S-…`)에 [사후] 꼬리표만.

```text
간이 작업기록 · 사후 작성                                      [사후]
╭ ▲ VF2-01 10:20~10:45 (25분) 정지에 대한 기록이에요 · 작성은 지금 13:05 ╮
설비 VF2-01 · 작업 [10:20]~[10:45] · 급했던 이유 [안전][고장 번짐][품질][그 밖]
한 일 (메모) [ … ] [이브로 정리] → 원인 · 조치 · 사용 부품
잠금·표지 (●) 했다 → 9칸  ( ) 안 했다 → 이유 (필수, 보기 화면에 빨간 줄)
사진 (선택) ▢ ▢ ▢ 최대 3장 · 이브에게는 보내지 않아요
[저장] [확정]                    → 반장 [확인]까지 가야 끝
```

| 정한 것 | 내용 |
|---|---|
| 누가 | 작업자·보전 담당이 씀, 잠금·표지를 했거나 부품을 썼으면 보전만 확정, **반장 확인 필수** (Q2·Q6) |
| 시각 표시 | 모든 작업기록 머리에 `알람 10:00 · 작업 10:00~10:15 · 작성 12:30`처럼 나란히만, "늦게 씀" 꼬리표 없음 (Q11) |
| 사진 | 모든 작업기록에 선택 첨부, 최대 3장 (Q10) |

| 안 하는 것 | 사후 작업지시서 (Q7), 사람별 순위·점수 |

  - B. 설비를 눌러도 확대만, 정보는 안 보임
  - C. 오른쪽 하단을 잠깐 설비 정보로 바꿨다가 닫으면 작업지시 진행으로 돌아옴
