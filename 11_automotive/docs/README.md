# docs/ — 근거 자료 조사 기록

이 프로젝트는 설비·알람·안전·품질 자료를 많이 조사해서 만들었다. 이 폴더에는 **우리가 직접 쓴 조사 문서와 출처 목록만** 남겼다.

## 원문은 왜 없나

제조사 매뉴얼(Haas·Siemens 등)과 그 번역본, 논문, 보도자료, 표준 문서, 웹페이지 저장본은 저작권이 우리에게 없어서 공개 저장소에서 뺐다 (2026-10-27, 팀 합의).
필요하면 각 폴더의 `_출처목록_*.md`에 적은 주소에서 직접 받는다.

## 남아 있는 것

| 종류 | 위치 | 설명 |
|---|---|---|
| 조사 문서 | `background/데이터보관/`, `line/3D_설비규격/`, `production/운영기준_근거/`, `quality/CMM_자동입력/` | 기획·설계서가 근거로 쓴 조사 결과 (직접 씀) |
| 출처 목록 | 폴더마다 `_출처목록_*.md` | 어떤 자료를 어디에서 받았는지(주소·이용 조건) |
| 팀원 작업 노트 | `team_notes/` | 파트별 기능 정의와 근거 정리 (v3 이전 기획서 기준) |

## 이 자료와 프로젝트의 관계

- AI 비서가 검색하는 지식은 이 폴더가 아니라 `../가상사내문서/`(팀이 원문을 바탕으로 한국어로 다시 만든 사내 문서 7종 + 용어집)이다.
- `../analysis/`의 일부 스크립트는 원문을 읽도록 쓰여 있어서, 원문 없이는 다시 돌릴 수 없다 (결과 요약은 `analysis/outputs/`와 각 보고서에 남아 있다).
- 다시 올리지 않도록 `.gitignore`에 원문 형식(pdf·html·docx·txt·csv·json)과 `haas/`·`kosha/` 폴더를 막아 두었다.
