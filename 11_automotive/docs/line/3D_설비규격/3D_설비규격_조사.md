## 2. 좌표 규칙 [가상]

| 항목 | 값 | 이유 |
|---|---|---|
| 원점 | 공장 안쪽 **남서쪽 벽 모서리, 바닥** | 라인 시작(OP-10)이 원점 가까이 오게 |
| X | 동쪽(+), **공정 흐름 방향** (OP-10 → OP-50) | 좌표만 보고 공정 순서를 알 수 있게 |
| Y | 북쪽(+), 주 통로에서 멀어지는 방향 | 통로가 Y 작은 쪽 |
| Z | 위(+), 바닥 = 0 | — |
| 단위 | mm | 제조사 자료 단위 |
| 설비 좌표 | **바닥 사각형의 가운데 (cx, cy)** + 크기(가로 X × 세로 Y × 높이 Z) | 상자 하나로 그릴 때 바로 쓰게 |
| 설비 정면 | 모두 **−Y(남쪽, 통로 쪽)** 을 봄 | 작업자는 통로 쪽에서 문·조작반을 씀 |
| 3D 엔진 좌표 | 엔진마다 위쪽 축이 다름 (예: Y가 위인 엔진이면 엔진(x, y, z) = (X, Z, −Y)) | 엔진은 기술 회의에서 정함 [선택 필요: 기술 회의] |
