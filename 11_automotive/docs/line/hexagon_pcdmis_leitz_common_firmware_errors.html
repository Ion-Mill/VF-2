Common Firmware Errors

You can diagnose errors and failures that may occur during the operation of the Common Firmware as follows:

  • If an error occurs during the execution of a command, review the error message that the controller immediately sends.

  • If the interface software is active, review the error message that appears.

The right-hand columns in the tables below list the error messages that may appear.

The controller's firmware stores the last error condition until you reapply power. You can then analyze the condition. To analyze it, you need to connect to the controller through the HyperTerminal application and STATUS command, or use the TESTSOFT program and function 1 SYSTEM STATUS. A series of informational messages appears and displays an "Error" field that contains a STATUS label with the type of error. The left-hand columns in the tables below list the STATUS labels that may appear.

excess_lag :

ERROR MOTOR_RE,S%1,TR_FG002,Excess Lag Error

The firmware detected that the position (the real axis position with respect to the position set) exceeded the maximum limit. This error may be due to one of the following:

  • A motor overload due to obstacles to motion (such as a collision or friction)

  • A motor failure

  • A failure of the motion mechanical system, servo driver, position transducers, or tacho

  • When the controller first connects to a machine, the cause may be a wrong servo adjustment, or the parameter MAX_LAG of the CONSTANT has a small value
