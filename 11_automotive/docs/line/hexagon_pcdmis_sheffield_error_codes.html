Error Codes

The software uses error codes to alert you of warnings and error conditions that occur within the Coordinate Measuring System (CMS). The CMS consists of a coordinate measurement machine (CMM), the CMM's electronics, and a personal computer (PC) running MeasureMax+ or MaxLite.

Error codes are denoted by a group name, a hyphen, and a number. A few examples are MP-523, MLB-010, and TempComp-200. The error codes in this section are specific to the Sheffield components, which include the CMM's electronics and Measurement Library (MLB) commands.

The error groups are:
