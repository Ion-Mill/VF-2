Keypad
 - Troubleshooting Guide
Introduction
Keyboard I/O Tab
Under Diagnostics, there is a Keyboard I/O tab that provides information on all the keyboard I/O input and output signals.
Each input and output is listed with its description and a value. If the value is 1, the input/output is triggered. If the value is 0, the input/output is not triggered. 
The RJH is an extension of the keyboard, therefore the RJH outputs are included in this tab. The inputs are triggered by the user on the RJH, while the value of the output is listed--either 0 or 1 again. 
These I/O signals can be used to better troubleshoot the system.
Key History Tab
Under Alarms, there is a Key History tab that keeps track of any used key. This keeps a record of each key used and the date & time it was used at. 
This information can be helpful to test keypad function or to troubleshoot a specific alarm or problem. 
Symptom Table
Symptom
Possible Cause
Corrective Action
A keypad button sticks or does not actuate when pressed.
The flex cable from the keypad to SKBIF PCB is damaged.
Inspect the cables and the connections.
The dome for a specific key fails to make a contact.
Alarm 546
 Serial Keyboard Buffer Overflow
One or more keys are stuck.
Go to the Key History and see if there are keystrokes being generated without the buttons being pressed. For NGC press the [ALARMS] button and go to the Key History tab. Find out which key is getting stuck and determine if the keypad is defective.
Machines with SKBIF Version 6.xx. 
Alarm 546
 SERIAL KEYBOARD BUFFER OVERFLOW.
The SKBIF firmware is outdated.
Make sure you have SKBIF firmware version 6.6 or higher. Refer to 
SKBIF PCB / RJH Firmware Update - NGC
 procedure.
Pressing on the bezel activates keys or makes a popping sound.
The keypad is misaligned.
Follow the instructions in the section 
Keypad Alignment 
below.
Cable Connections
Corrective Action:
If any of the 24 wires fail to make connection, or if they have an intermittent connection, the keypad will malfunction.
Make sure the pins in the connector [1] on the SKBIF is in good condition.
Make sure the flex cable [2] is in good condition. A broken trace or open contact will cause a row or column to be inoperative.
Replace the keypad if the cable is damaged.
Keypad Alignment
1
Loosen the outermost screws on the bottom half of the bezel as shown.
2
Adjust the keypad as needed so the keys are centered.
When the keypad has been centered, install the remaining screws.
