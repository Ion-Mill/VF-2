NGC Software
 - Troubleshooting Guide
Introduction
Use this document to troubleshoot software issues and update problems on a machine with the Next Generation Control. If you can not find the scenario that matches your situation, please submit an error log (
[SHIFT]
 +
 [F3]
) to 
[email protected]
.
 Note
: If necessary the error log command (
[SHIFT]
 +
 [F3]
) can be initiated while the program is running.

Symptom
Possible Cause
Corrective Action
Alarm 9191 Machine Moved
N/A
Contact your HFO. 
Find Your Distributor
After a software update, the control won't boot up or hangs at the Haas logo.
The software version is not compatible with the processor installed.
Check the processor part number and ensure the correct software version was installed. For more information, see the Hardware and 
Software Version Compatibility Table
.
The software did not load correctly.
Use a SanDisk Extreme USB 3.0 USB device to load the software. Reload the software using option 5) Perform Clean Software Install. Refer to 
Next Generation Control - Software Update - Clean Installation
.
Machine delivered in factory mode./The machine arrives at the customer activated.
Machine shipping is faster than expected.
The machine must exit Factory mode. To exit factory mode, do the following. 
To enter service mode, insert a USB stick with a service key. Then, press 
[Alarms]
, type in "Debug" and press
 [Enter]
.
Remain on the Alarms page and type in "FMTIME60". 
Wait 3 minutes. 
After existing factory mode and will need to be activated. 
Go the the section "Factory Mode" Below for more details. 
The machine will not boot to the software updater screen when powering on and holding the U button.
The machine lost power during a software update.
Do not replace the processor. Try to recover the software using the 
Software Update Recovery - NGC
 procedure.
The software files are corrupted.
The USB device failed during a software update.
Machines with software version prior to 100.17.000.2034. The control freezes, there is a blank monitor, a black screen, the keypad does not work, won't boot sometimes, random shutdowns, or software alarms.
The parameters for the Q7 module on the Maincon PCB are outdated.
The updated parameters have been incorporated into the software version 100.17.000.2034 (TP 21894). Update the software to the latest version. If the symptoms continue after updating the software, download the error log with 
[SHIFT]
 +
 [F3]
 and e-mail it to Haas Service Department.

Software issue since release 
100.22.000.1011
.
Update the machine to the latest software version and download and load the latest configuration files from the service portal.

Alarm 9972
 FPGA CONFIGURATION FAULT.
The FPGA software did not get loaded correctly during the software update.

Next Generation Control - Software Update - Clean Installation

Alarm 9933
 - SOFTWARE VERSION MISMATCH
The configuration files loaded to the control do not match the software version on the machine.
Make sure the configuration file that is being loaded matches the software version on the machine.
Download the configuration file from the portal
Add the .zip extension and unzip the files.
open the _cv.xml file in notepad
search for keyword: Software Version make sure the software version matches the software version on the machine.
 If the configuration file is correct:
Try reloading the configuration files again. Refer to: 
Next Generation Control - Configuration File - Download/Load
If that does not work reload the software using option 5) Perform Clean Software Install. Refer to: 
Next Generation Control - Software Update - Clean Installation
.
Alarm 9934 - 
INTERNAL VARIABLE NOT INITIALIZED
The configuration files loaded on the control do not have all settings that the new software has.
Make sure you load the latest configuration file for the software version you have on the control.
The Z Axis does not jog and can not do a tool change after a software update.
Option 5 Clean Software Install was selected for software update and theserial_number.fs file in the configuration folder is missing.
Make sure the Factory Settings File box is checked when you download the configuration files. Make sure theserial_number.fs file is in the configuration folder.
The software was updated to the latest version from a machine that had software version 100.16.000.1020 or lower.
Load software 
100.16.000.1021
 first then you can upgrade to the current software version. This version is located on the portal.

Alarm 9927 
Motion Channel Unable To Initialize
The software encountered an error.
If the machine does not have the latest sofware: Cycle power the machine, is the alarm present? If no, continue to use the machine. If yes, update the machine software to the latest.
If the machine has the latest software or alarm is generated again after updating software. Send an error report to the Haas Service Department. Cycle power the machine, is the alarm present? If no, continue to use the machine. If yes, cycle power machine until alarm is no longer present. If the alarm does not go away contact the Haas Service Department.

Factory Mode
 Note:
 Do not attempt to put a machine in factory mode. This is only for machines in the factory that are being assembled. 
To see if a machine is in factory mode, go to 
[Diagnostics]
 -> 
[Parameters]
 -> 
[Activation]
. If the machine is in factory mode, it will say "Factory Mode On" [1] at the bottom of the activation page.
1
If a machine is in factory mode, the service technician must exit factory mode before starting the installation. 
To exit factory mode, do the following. 
To enter service mode, insert a USB stick with a service key. Then, press 
[Alarms]
, type in "Debug" and press
 [Enter]
.
Stay on the Alarms page and type in "FMTIME60". 
Wait 3 minutes. 
After the existing factory mode, the machine will need to be activated.
