# 찐 — Haas VF-2 (NGC) 공식 문서 보관소

이 폴더에는 프로젝트 대상 설비 **Haas VF-2 수직 머시닝센터(NGC 제어기, 표준 사양, 15″ 화면 가정)**에 해당하는 **Haas 공식 문서만** 모아 둡니다. 알람 카드, 작업지시서, 챗봇(RAG), 가상 데이터는 모두 이 폴더의 문서를 근거로 만듭니다.

> **처음 왔다면 [`index.html`](index.html)을 브라우저로 여세요.** 기능별로 문서가 정리되어 있고, "읽기"를 누르면 본문만 바로 볼 수 있습니다.

## 꼭 지킬 것

- **공식 문서만 근거로 씁니다.** 알람 번호·의미, 점검 순서, 안전 절차, 센서 종류, 기준값, 부품번호는 이 폴더의 문서에서 찾은 것만 씁니다. 못 찾으면 쓰지 않습니다(`.claude/rules/common-project-goal.md` 「실제 매뉴얼 기반 의무」).
- **내부 참고용입니다.** 모든 문서는 Haas 저작물입니다. Haas 약관에 "서면 허가 없이 사용 불가" 조항이 있으므로 외부에 공유하거나 공개 저장소에 올리지 않습니다. 앱 화면에 원문을 얼마나 보여줄지는 **보류** 중입니다.
- **원본은 고치지 않습니다.** 새 개정판은 새 파일로 추가하고, 기존 파일은 덮어쓰지 않습니다.

## 어떤 파일을 열어야 하나

문서 하나당 파일이 여러 개 있습니다. 용도에 맞는 파일을 여세요.

| 파일 | 용도 | 비고 |
|---|---|---|
| `…__body.html` | **사람이 읽기** | 본문만 뽑은 파일. 맨 위에 출처표가 있다. 그림은 Haas 공식 주소에서 불러오므로 인터넷 연결 시에만 보인다 |
| `…__body.md` | **검색·RAG 입력** | 사이트 메뉴를 뺀 본문 텍스트. RAG 청킹에는 이 파일을 쓴다 |
| `….html` (원본) | 증거 보관·사실 확인 | 수집한 그대로. 사이트 메뉴가 본문 앞에 길게 있고, 메뉴 링크를 누르면 로컬에서는 404가 난다(정상) |
| `….md` (원본 변환) | 사용하지 않음 | 원본 전체를 변환해 메뉴가 섞여 있다. `__body.md`를 쓴다 |
| `….meta.json` | 출처 정보 | URL, 수집 시각, HTTP 상태, 해시, 개정, 적용 범위 |
| `….pdf` / 같은 이름 `.md` | PDF 원본 / 쪽 표식 변환본 | `<!-- page: N / 총쪽수 -->` 표식이 있다. 읽기 순서는 원본 PDF와 대조 필요 |
| `….ko.md` | 번역본 | **탐색용만.** 사실 근거로 쓰지 않는다 |

파일 이름 형식은 `<문서번호>__<개정>__<수집일>.<확장자>`입니다. 개정 표기가 없는 문서는 `norev`이고, archive.org 사본은 끝에 `__archive`가 붙습니다.

## 다시 만들기

모든 명령은 `C:\code\1`에서 실행합니다. Python은 PyMuPDF·MarkItDown이 설치된 `C:\Users\CM\AppData\Local\Programs\Python\Python312\python.exe`를 씁니다.

```bash
# 1) 공식 문서 수집 (robots.txt Crawl-delay 10 준수, 요청 간 11초)
python scripts/collect_ngc_docs.py                 # 전체
python scripts/collect_ngc_docs.py --only ngc_992  # 일부만

# 2) PDF를 쪽 표식 Markdown으로 변환
python scripts/convert_pdf_pages_markitdown.py "<pdf 경로>" --out "<md 경로>"

# 3) HTML 원본에서 본문만 추출 (__body.html, __body.md, _body_report.csv)
python scripts/extract_ngc_body.py

# 4) 목록 페이지 갱신
python scripts/build_ngc_index.py
```

- 수집 스크립트는 Git의 curl(`C:\Program Files\Git\mingw64\bin\curl.exe`)을 씁니다. Windows 기본 curl은 Haas 사이트에서 403을 받습니다. 403은 간헐적으로도 나므로 실패하면 시간을 두고 다시 실행합니다.
- 기존 파일은 덮어쓰지 않습니다. 본문 추출을 다시 하려면 `__body.html`, `__body.md`(생성 파일)만 지우고 3)을 실행합니다.
- 새 문서를 추가하면 `collect_ngc_docs.py`의 목록에 넣고 1) → 3) → 4) 순서로 실행합니다.

## 현재 상태 (2026-10-03)

- 수집: manifest 72행(문서 51개 파일, 장 페이지 안의 개별 문서 포함). collected 71, superseded 1(운영자 매뉴얼 Rev N).
- 본문 추출: 44개 중 ok 43. NGC 전기 매뉴얼 첫 페이지(ESM-00)는 JavaScript로 그리는 페이지라 정적 본문이 없어, 다른 장 페이지에서 뽑은 장 목록(`NGC-ESM-00__chapter-index__from-ESM-12-nav.md`)으로 대신한다.
- 시연 알람: 주 시나리오 1.992(X축 앰프 과전류, 선행 1.994), 보조 1.993·120·2073·991. **135·179는 NGC 공식 정의가 없어 쓰지 않는다.**
- 받지 않은 문서: 기어박스 장(표준 VF-2에 없음), Chip Removal and Coolant, 서비스 공지(robots.txt 차단 경로), 운영자 매뉴얼 Rev V(19″ 장비용).

## 알려진 한계

- 그림은 온라인 연결이 있어야 보입니다(로컬에 그림을 저장하지 않음).
- PDF 변환본은 쪽 표식과 글리프는 확인했지만 **읽기 순서는 PDF와 육안 대조하지 않았습니다**. 특히 2단 편집 쪽과 다른 방식으로 다시 추출한 쪽(각 PDF의 `verification-summary.json` 참고)은 인용 전에 원본을 확인합니다.
- 온라인 문서의 표(저항·전압 허용범위 등)는 HTML 표에서 추출했으므로, 수치를 인용하기 전에 원본 화면과 대조합니다.
- Haas 문서는 개정이 잦습니다(2025~2026년 다수). 주기적으로 다시 수집해 해시를 비교합니다.
