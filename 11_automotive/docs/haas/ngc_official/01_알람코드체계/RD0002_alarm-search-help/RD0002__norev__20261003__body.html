Alarm Search Help Guide

RD0002

Alarm Search Help

The Next Generation Control (NGC) alarm numbers have several formats.

1. The standard format alarm number [A] has no decimal points. These alarm numbers are for both Classic Haas Control (CHC) and Next Generation Control (NGC). For example: Alarm 107 E-stop.

2. For alarms that are related to the machine axis, the number before the decimal point [B] is the axis number. The (4) numbers after the decimal point [C] is the alarm number. For example: Alarm 1.9930 X SERIAL ENCODER COMMUNICATION FAULT.

Note: In the Alarm Viewer in the control, you can search only for the alarm "9930" number. On the Haas Service Site you can search for the entire alarm number "1.9930" or the axis alarm "9930".

Note: The numbers of the axis are the same as in the NGC parameters. The axis number is not always the same as the physical board address numbers. Refer to Next Generation Control - Axis Assignments for more information.

3. For alarms that have (4) numbers before the decimal point [D], this is the alarm number. Most of the (3) numbers after the decimal point [E] are sub-alarm numbers that are used to provide more information related to the alarm. For example: Alarm 9100.018 NON RESETTABLE Software Error.

Note: The 20000 alarms (20000-20017 currently) are informational messages only. These are usually generated at power up and only show in the alarm history. This information is used by our software developers for debugging purposes. They typically do not require any service action. Refer to System Messages & Notifications for more information.
