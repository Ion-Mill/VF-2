## Alarm Search Results:**314****SUBPROGRAM NOT IN MEMORY**

---

Check that a sub-program called by the P code in M98 or G65 is in memory. When calling a sub program with FNC the sub program must reside on the same device and in the same directory as the main program, which calls them. Also, for files that were transferred from USB to hard drive check the case of the file name on the hard drive, sub programs called must have upper case O and lower case extensions. For example: O1234.nc.
