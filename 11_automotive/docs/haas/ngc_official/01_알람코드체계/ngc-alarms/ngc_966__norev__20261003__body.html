Alarm Search Results: 966 EXCESSIVE TOOL IMBALANCE

There is a vibration sensor built into the main processor that detects excessive vibration. All machine movement has stopped, due to a potentially dangerous vibration. Check for bent or damaged tools. Never use damaged or imbalanced tools. After you correct the cause of the excessive vibration, you can continue normal operation. If your application requires machine vibration greater than allowed, you can use Setting 245 to adjust the vibration sensitivity. Note: This alarm can also be generated if the main processor mounting hardware or if the electrical control mounting hardware is not secured properly.
