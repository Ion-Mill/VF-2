## 2. QLT-01 검사 기록·불량 집계

### 2.1 하는 일
OP-50(3차원 측정기) 측정값을 저장하고, 항목별 합격·불합격, 공정능력(Cpk·Ppk), 불량 추세를 보여 줍니다.

### 2.2 검사 기준 (`inspection_spec`)

| 항목 코드 | 항목 | 기준 | 하한 / 상한 | 평소 빈도 | 근거 |
|---|---|---|---|---|---|
| BORE_D | 베어링 구멍 지름 | Ø45 H7 | 45.000 / 45.025 | 전수 | [실제 등급] MISUMI 구멍 공차표, ISO 286 IT7 |
| LEN | 전체 길이 | 150 ± 0.5 | 149.5 / 150.5 | 전수 | [실제 등급] ISO 2768-m (EnerSys p3) |
| THK | 두께 | 12 ± 0.2 | 11.8 / 12.2 | 전수 | [실제 등급] ISO 2768-m |
| HOLE_DIST | 구멍 간 거리 | ± 0.1 | 가상 도면값 | 전수 | [가상] |
| FLAT | 평면도 | 0.05 이하 | — / 0.05 | 교대당 3개 | [가상] 도면값, 빈도는 Nemak 2023 |
| M6 | M6 나사 | 통과·정지 게이지 | 합격 여부 | 교대당 3개 | [실제] Vermont Gage 판정 원리, 6H |

- 특별 특성(공정능력 1.67 적용): BORE_D **[가상 지정]**. 베어링이 들어가는 기능 치수라서입니다. 기준 근거는 Ford PPAP p17, Nemak 2023 **[실제]**입니다.
- 측정 조건: 기준 온도 20 °C (ISO 1, NIST JRES 121) **[실제]**. 측정점 수는 NPL GPG41을 따릅니다.

### 2.3 테이블

| 테이블 | 주요 칸 |
|---|---|
| `inspection_spec` | spec_code, 제품, 항목명, 공칭값, 하한, 상한, 판정 방식(수치/합부), 특별 특성 여부, 평소 빈도, 강화 빈도, 근거 |
| `inspection_result` (기존 수정) | id, **lot_id(=작업지시)**, **부품 일련번호**, 설비, spec_code, 측정값, 합부, 측정 시각, 측정자, 검사 구분(평소/강화/재검사) |
| `defect_code` | 코드, 대분류, 불량명, 정의, 심각도(치명/중/경), 연결 검사 항목, 대표 원인 |

### 2.4 계산 로직

**합부 판정**: 하한 ≤ 측정값 ≤ 상한이면 합격. 게이지 항목은 통과 게이지 들어감 + 정지 게이지 안 들어감이면 합격입니다.

**공정능력** (BORE_D, LEN, THK, HOLE_DIST)
- 서브그룹: 연속 부품 5개. 최근 25개 서브그룹(125개)으로 계산합니다 [실제: Ford PPAP p16].
- 서로 다른 작업지시에 걸쳐도 같은 제품·설비면 이어서 계산합니다. 작업지시 1건은 평균 36개라 125개에 못 미치기 때문입니다.

```
σ_within  = R̄ / d₂   (n=5 → d₂ = 2.326)        [실제: NIST 6.3.2.1, Minitab methods]
σ_overall = 표본 표준편차 s (전체 125개)          [실제: Minitab overall capability]
Cpk = min(USL − x̄, x̄ − LSL) / (3 · σ_within)
Ppk = min(USL − x̄, x̄ − LSL) / (3 · σ_overall)
```

- 판정 기준: 일반 특성 ≥ 1.33, 특별 특성 ≥ 1.67 [실제: Ford CSR p35, Ford PPAP p17, Cummins p17, Nemak 2023]
- 미달이면 "100% 검사 필요" 표시와 로트 보류 규칙 H3을 실행합니다 [실제: Ford Table A, Nemak].
- **검증**: `box_MultiSPC.xlsx`의 특성별 Pp·Ppk를 정답으로 놓고, 같은 측정값(`FAIR_Box_Results.qif`)으로 계산한 값이 일치하는지 단위 테스트합니다.

**관리도·추세**
- 수치 항목은 X̄-R 관리도(n=5), 불량률은 p 관리도입니다 [실제: NIST 6.3.2.1, 6.3.3.2].
- 알림에는 **규칙 1(3σ 밖)만** 씁니다. 나머지 Western Electric 규칙은 화면의 점 색으로만 표시합니다. 이유: 규칙을 모두 쓰면 오경보가 371점 → 약 92점에 1번으로 늘어납니다 [실제: NIST 6.3.2]. 기획서 4.3 "알림이 너무 많으면 아무도 안 본다"와도 맞습니다.

**불량 집계**
- 불량률 = 불합격 수 ÷ 검사 수 (일·교대·작업지시·항목별)
- 내부 PPM = 불합격 수 ÷ 검사 수 × 10⁶ [실제: Danfoss p38, Cummins p10의 정의를 내부 공정에 적용]
- 파레토: 불량 코드별 건수

### 2.6 화면
1. **검사 기록 표**: 로트·부품별, 불합격 빨강
2. **공정능력 카드**: 항목별 Cpk·Ppk와 기준선 1.33/1.67. 미달은 주황
3. **관리도**: X̄·R, 3σ 밖 점 강조
4. **불량 추세·파레토**

PRD-01 화면에는 요약 숫자(오늘 불량률, Cpk 미달 항목 수)만 넘깁니다.

## 3. 로트 보류 (QLT-02 제안)

### 3.1 로트 구조
- 가공 로트 = 완제품 로트 = **작업지시 번호** (`PO-2609-015`) [가상, 최소화]
- 작업지시 1건이 쓰는 원소재 로트는 최대 2개 [실제 응용: Bosch SQR 6장 "포장당 배치 번호 최대 2개"]
- 구조는 ISA-95 MaterialLot → Sublot을 단순화했습니다 [실제: OPC 10030]

### 3.2 테이블

| 테이블 | 주요 칸 |
|---|---|
| `lot_hold` | hold_id, lot_id, 사유 코드(H1~H3, 소재), 부품 범위(시작·끝 일련번호), 보류 시각, 제안/자동, 상태, 제안자(비서/사람), 확정자, 해제자, 해제 시각, 처리 결과, 메모 |
| `lot_hold_recheck` | hold_id, 부품 일련번호, spec_code, 측정값, 합부 |
| `production_order` (기존 수정) | `lot_status` 칸 추가: 가용 / 보류 / 불합격 / 출하 완료 |

### 3.3 상태
- 로트: 가용 → 보류 → 가용(해제) / 불합격 / 출하 완료
- 보류 기록: **제안됨** → 열림 → 재검사 중 → 해제 / 선별 후 해제 / 폐기
- 확정·해제 권한: 반장(SUP)·관리자(MGR) [실제: 기획서 11장]
- 보류 로트는 출하 API가 거부합니다 [실제: Danfoss 6.4 "특채 없이 출하 금지"].

### 3.4 보류 규칙

| 규칙 | 조건 | 범위 | 근거 |
|---|---|---|---|
| H1 | OP-30 설비에 정지 등급 알람(992, 994, 991, 993, 103, 966) | 그 설비의 마지막 합격 부품 다음 ~ 알람 시점까지 가공 부품 | [실제] Ford CSR p36 Table A |
| H2 | OP-50 불합격 발생 | 같은 로트 나머지 | [실제] MIL-STD-1916 합격 판정 개수 0 |
| H3 | 최근 125개 기준 Cpk < 1.33 (특별 특성 < 1.67) | 진행 중 로트 | [실제] Ford Table A, Nemak |
| H4 (선택) | 공구 수명 한계(362 알람) 또는 공구 수명 100% 초과 | 교체 전 마지막 부품까지 | [가상] 설계서 5.4 공구 수명 90% 이후 불량 증가 |
| HM | 원소재 성적서 성분이 6061 한계 밖 | 원소재 로트와 그 소재를 쓴 작업지시 | [실제] Aluminum Association 성분표 |

### 3.5 검사 강화와 해제

| | 평소 | 보류 중 |
|---|---|---|
| 치수 4항목 | 전수 | 전수 |
| 평면도, M6 게이지 | 교대당 3개 | **전수** |
| 해제 조건 | — | 대상 부품 전부 재검사, 불합격 0개 → 해제. 불합격이 있으면 그 부품만 빼고 해제 |
| 처리 기한 | — | 보류 후 24시간 안에 재검사 결과 [가상 적용: Cummins p31, SMP p5의 격리 24h] |

일반·강화 검사 전환 개념은 MIL-STD-1916에서 가져왔습니다 [실제].

### 3.6 추적
- 역추적: 완제품 로트 → 원소재 로트 (`lot_link`)

- 근거: Diehl p21 "영향받는 제품 즉시 특정", Bosch SQR "1일 내 추적" [실제]

## 4. INV-A 예비 부품·소모품 재고 [제안]

### 4.1 테이블

| 테이블 | 주요 칸 |
|---|---|
| `spare_item` | P/N, 품명, 분류(윤활유/필터/전기/기계), 대상 설비, 단위, 중요도(V/E/D), 단가, 리드타임(일), 보관 위치, 근거 |
| `spare_stock` | P/N, 현재고, 예약 수량 → 가용 = 현재고 − 예약 |
| `spare_txn` | 시각, P/N, 구분(입고/출고/예약/예약 취소/조정), 수량, 정비 작업지시 번호, 담당자 |

### 4.2 중요도와 재주문점

| 중요도 | 정의 | 정책 | 서비스 수준 |
|---|---|---|---|
| V 필수 | 없으면 설비 전체 정지 | 결품 불허, 최소 1개 보유 | 99%, z = 2.33 [가상 수치] |
| E 중요 | 부분 정지·품질 손실 | 재주문점 (r, Q) | 95%, z = 1.65 [실제 예시: Teixeira 2024] |
| D 보통 | 정지 없음 | 최소 0·최대 1. 단납기·고가 품목은 무재고 | 90%, z = 1.28 [가상 수치] |

등급 정의·정책 근거: TU Eindhoven 2010, Teixeira 2024, DoDM 4140.01 [실제]

```
재주문점 R = d̄ · L + z · σ_d · √L                     [실제: KOCW 재고관리 2강, MIT ESD.260J 11강]
안전재고 상한 = min(3 · σ_d · √L, d̄ · L)               [실제: DoDM 4140.01 Vol.2 p49]
가용 ≤ R → 발주 알림
```

| 테이블 | 주요 칸 |
|---|---|
| `tool_item` | 품목, Haas Tooling P/N, 종류, 수명 한도, **한도 단위(HOLES / FEED / USAGE)**, 리드타임, 최소·최대 |
| `tool` (기존, ML-01) | T번호, 설비, 품목, 누적 사용량, 한도 |
| `tool_stock` | 품목, 새 것 수량, 재연마 대기 수량 |
| `tool_txn` | 시각, 품목, 구분(예약/출고/폐기/재연마 보냄/입고), 수량, 관련 T번호 |

### 5.2 수명 한도

| 공구 | 한도 | 근거 |
|---|---|---|
| M6 탭 (03-1818) | 구멍 400개 (HOLES) | OSG ADC12 M6 500홀 후 정상 × 0.8. 학회 논문 Al6061 M8 450홀, 강재 M6 300~500홀과 일관 [실제, 하한 근거] |
| Ø10 3날 엔드밀 (03-1011) | 이송 120분 (FEED) | Materials 2023: Ø10 3날 초경, Al7050, 200분 급마모 진입 × 0.6 [실제, 합금 다름] |
| Ø5 드릴 (03-1513) | 구멍 1,000개 | [가상] 인용할 수치 없음 |
| Ø45 정삭 보링 인서트 | 부품 250개 | [가상] 인용할 수치 없음. BORE_D 추세로 함께 감시 |

> **설계서 5.11 수정 필요:** "탭 400회, 엔드밀 800회"는 Haas USAGE(공구 호출 횟수, 부품 1개 = 1회) 기준이면 근거를 넘습니다. 부품당 탭 구멍이 4개면 400회 = 1,600홀입니다. 탭은 HOLES, 엔드밀은 FEED로 바꾸는 것을 데이터·ML 담당과 협의합니다 [실제: Haas Mill NGC 매뉴얼 Rev T §4.11.2].

### 5.3 흐름

```
ML-01 수명 90% ─▶ 교체용 1개 예약 ─▶ 교체 완료: 새 것 출고
                                    └▶ 헌 것: 탭·드릴은 폐기, 엔드밀은 재연마 대기 [가상 규칙]
새 것 ≤ 최소 ─▶ 발주 알림
```

```
일 교체 수 = 일 생산량 × 부품당 사용량 ÷ 수명 한도
최소 = 일 교체 수 × 리드타임 + 안전재고(1)
```

## 11. 팀이 정할 것

1. 재고 기능을 다시 넣을지, 넣는다면 INV-A/B/C 중 어디까지
2. 로트 보류를 8장 기능(QLT-02)으로 올릴지
3. 비서 행동 범위 안 A / 안 B / 중간안
4. 공구 수명 한도 단위 변경(설계서 5.11)
5. 가상 값: 평면도 0.05, 구멍 간 거리 ±0.1, 서비스 수준 99%·90%, 보류 처리 24시간, 드릴·보링 수명
