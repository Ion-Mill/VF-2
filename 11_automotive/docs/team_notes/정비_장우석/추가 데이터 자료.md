### CSV를 읽을 때 주의

- **첫 줄은 `Column1~Column131` 자리표시, 둘째 줄이 실제 열 이름이다.** 메모에 "열 이름을 매핑해야 함"이라고 되어 있지만, 둘째 줄을 머리글로 읽으면 된다.
- 구분자는 `;`, 일부 숫자는 소수점이 쉼표다 (예: `36,67`).
- 메타 열: `FileName`, `NumberOfCycle`, `SampleIndex`, `TollIndex`(원문 오타), `MillingToolType`, `ADOC`, `RDOC`, `HardnessMean`, `ToolHolderLength`, `CycleToFailure`, `CycleToFailureNormalized`

**읽을 수 있는 것**

- RDOC 8mm(제조사 권장을 넘는 조건) 공구 5개는 수명이 **29~53 사이클**로 짧다. 정상 조건과 섞으면 안 된다.
- 정상 조건(RDOC 4.5mm)에서 이상치 2개를 빼면 수명이 **59~149 사이클**, 평균 약 106이다. 평균 대비 **0.56배에서 1.41배까지** 흔들린다.
- 같은 조건에서도 2.5배 차이가 난다. "공구 수명은 공구마다 크게 다르다"는 설계서 3.1의 설명이 이 숫자로 뒷받침된다.

## 4. 팀원 메모와 다른 점 (바로잡을 것)

| 메모 내용 | 확인 결과 | 어떻게 할지 |
|---|---|---|
| 열 이름이 Column1~131이라 매핑 필요 | 둘째 줄에 실제 이름이 있음 | 둘째 줄을 머리글로 읽기 |
| 원본 신호 약 112 GB | Figshare 압축 파일은 25.3 GB. 112 GB는 압축을 푼 크기일 수 있으나 확인 못 함 | 어차피 받지 않음 |
| 회전수·이송·지름 고정 | 맞음. 다만 **홀더 길이(80 / 160mm)도 바뀜** | 변수로 포함 |
| **목표 성능 R² 93% 이상** | 93.9%(신경망)·93.4%(SVR)는 메모에만 있고 어떤 방식으로 나눠 검증했는지 확인 못 함. 이전 팀 분석에서 **처음 보는 공구** 기준 R²는 0.55~0.65였음 (기획서 ML-01) | **93%를 목표로 잡지 않는다.** 공구 단위 검증 값만 발표에 쓴다 |
| LSTM 등으로 학습 | 가공 CSV는 사이클당 통계값 한 줄이라 시계열이 아님. LSTM은 원시 신호(25 GB)가 필요 | LightGBM 같은 표 데이터 모델 사용 (기획서 12.2) |
| 정비 문서(RAG용)를 따로 확보해야 함 | 기획서 v3에서 이미 "가상 사내 문서 세트 7종"으로 정해짐 | 추가 작업 없음 |

## 5. 우리 프로젝트에서 쓰는 곳

### 5.1 쓰는 곳

| 쓰는 곳 | 방법 | 화면·문서에 표시 |
|---|---|---|
| **ML-01 예측 모델** | 정상 조건 공구(RDOC 4.5mm, 이상치 제외) 7개 위주로 남은 수명 회귀 모델 학습. **공구 하나를 빼고 학습한 뒤 그 공구로 시험하는 방식**으로 검증 | 별도 "예측 실험" 화면. "실제 Haas 공구 수명 실험 데이터(강철)로 한 예측 실험"이라고 표시 |
| **가상 공구 기록 (D5)** | 가상 공구의 **실제 수명 = 한도 × 흔들림 배수**. 배수는 3장의 0.56~1.41배 범위에서 뽑는다. 사이클 수 자체는 옮기지 않는다 (소재가 다름) | 설계서 5.13 "편차 모양은 VF-1 실험 [참고]" |
| **공구 마스터 (M8)** | 한도를 정할 때 "같은 조건에서도 2.5배 차이가 나므로 한도는 평균보다 낮게 잡는다"는 근거 | [가상항목_근거자료.md](가상항목_근거자료.md) 2.2와 함께 |
| 알림 연결 | 공구 수명 90% 알림, 362(공구 수명 한계 도달), 174(공구 부하 초과)와 이어짐. 모델 값은 참고로만 | 기본 알림은 사용 횟수 기준 |
| 심사 대비 | "운영 데이터는 가상이지만 공구 모델은 실제 Haas 데이터로 학습했다" | 기획서 7.5, 17.2 |

### 5.2 쓰지 않는 곳

| 쓰지 않는 곳 | 이유 |
|---|---|
| MNT-01~05 (질문 답변, 카드, 작업지시서, 예방 정비, 작업기록서) | 정비 기록·알람·문장이 없는 센서 수치 데이터다 |
| OP-30 가상 센서 값 (주축 부하 % 등) | 이 데이터는 전류(A)·진동(g)이고 우리 화면은 Haas 부하(%)·온도(℃)라 단위가 다르다. 센서 범위는 설계서대로 Haas 원시 표본에서 빌린다 |
| 가상 공구 기록으로 모델 학습 | 가상 기록은 우리가 정한 규칙을 따르므로, 그걸로 학습하면 규칙을 다시 맞히는 것뿐이다 (설계서 5.13) |
| 알루미늄 공구 한도 숫자 | 소재가 강철이라 사이클 수를 그대로 옮길 수 없다 |

### 5.3 일정상 위치

- ML-01은 권장 기능이고, 일정이 밀리면 **가장 마지막에 줄인다** (기획서 8장).
- 모델이 빠져도 공구 알림은 사용 횟수 기준으로 그대로 동작한다. 시연 S3(T05 M6 탭 92%)에도 영향이 없다.
- 단, **D5의 수명 흔들림 배수는 모델과 상관없이 쓰므로** 데이터는 1주차에 받아 두는 것이 좋다.
