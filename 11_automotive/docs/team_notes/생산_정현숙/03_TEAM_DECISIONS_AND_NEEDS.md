## 0. 우선순위 요약

가상 데이터 생성기를 짜기 **전에** 결정해야 하는 것부터 적었다.

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | 시연 제품(1종/2종), 중간검사 추가 여부, 공정 사이클타임 | 데이터 구조와 크기가 바뀐다 |
| 2 | 작업지시 수량 분포, OP-50 측정 방식, 셋업 시간 표기 | 생성 규칙이 바뀐다 |
| 3 | 정지·불량 코드 체계, 작업지시 상태 값 | 테이블 정의가 바뀐다 |
| 4 | 비서 행동 범위(안 A/B/중간안), 알림 기준값 | 비서·화면 구현 범위가 바뀐다 |
| 5 | 저장소 공개 여부와 저작권 문서 처리 | 이미 커밋한 문서가 있다 |
