Lubricant, Grease, and Sealant Tables for Haas Machine Components
RD0040
Revision H - 12/2025

Introduction
This document contains the following tables:
The Lubricant tables contain the recommended lubricant type and capacity for Haas machine components.
The other tables contain information about the properties of the lubricants.
The Specialty Grease and Sealant tables contain the description and part numbers for each item in the table.
Go to WWW.HAASCNC.COM/HAAS-SERVICE-PARTS to order replacement parts and lubricants.
Note: The lubricants in this table are for all Haas machines made after 1989.
