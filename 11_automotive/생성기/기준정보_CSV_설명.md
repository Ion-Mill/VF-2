# 기준 정보 CSV 설명

> `생성기/masters/`의 CSV마다 **무슨 파일인지, 칸이 무엇인지, 값이 어떻게 들어 있는지** 적는다. 파일을 만들 때마다 이 문서에 더한다.
> 작성: 데이터·ML 담당 / 2026-10-10. 칸 이름과 뜻은 [논리ERD_최종본.md](../논리ERD_최종본.md) 5장, 코드 값은 6장과 같다.

## 0. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 파일 이름 | 논리 ERD 엔터티 이름 (예: `equipment.csv` = 설비) |
| 칸 이름 | 논리 ERD 속성 이름 그대로 (영문). 한국어 뜻은 아래 표 |
| 글자 | UTF-8, 쉼표 구분, 첫 줄 = 칸 이름 |
| 참·거짓 | `true` / `false` |
| 빈칸 | 값이 없음 (해당 없음, 또는 자료에 없음) |
| 길이 단위 | mm, 정수, 천 단위 쉼표 없음 |
| 코드 값 | 영문 대문자 코드 (ERD 6장). 이 문서의 "코드" 표 참고 |
| 다른 파일 가리키기 | 칸 이름이 같으면 같은 값 (예: `equipment.process_code` → `process.process_code`) |

**자주 나오는 코드**

| 코드 | 뜻 | ERD |
|---|---|---|
| `REAL` / `REFERENCE` / `VIRTUAL` | [실제] / [참고] / [가상] — 값의 근거 | 6.41 |
| `DAY` / `NIGHT` | 주간(08:00~17:00) / 야간(20:00~05:00) | 6.10 |
| `NEG_Y` / `POS_X` | 정면이 −Y = 남쪽(주 통로 쪽) — SAW-01 말고 5대 / 정면이 +X = 동쪽 — SAW-01 | 6.51 |
| `ELEC` / `ELEC_SUPPLY` / `AIR` | 전기 / 전기(공급 분전반) / 공압 | 6.21 |
| `BOX` / `CYLINDER` | 상자 / 원기둥 | 6.50 |

**좌표 읽는 법** (`plant_layout`): 원점은 공장 남서쪽 벽 모서리 바닥이다. X는 동쪽(공정 흐름 방향), Y는 북쪽, Z는 위쪽이다. 주 통로는 남쪽(Y 0~2,000)이고 설비 정면 선은 Y 3,800이다.

| `model` | 모델 | 예: Haas VF-2. MIL-01은 "3축 머시닝센터"(모델 [가상]) |
| `controller` | 제어기 | Haas / Haas NGC / Siemens 840D sl. WSH-01·CMM-01은 빈칸 |
| `std_cycle_min` | 기준 사이클 시간 (분/개) | SAW 1.0, MIL 3.5, VF-2 7.0, CMM 0.9(평소 발췌 평균). WSH-01은 빈칸(묶음으로 셈). 손실 수량 계산에 씀 |
| `batch_qty` / `batch_time_min` | 묶음 수량 / 묶음 시간 | WSH-01만: 30개를 모아 25분 |
| `has_sensor` | 센서 기록 | VF2-01·02만 `true` |
| `size_x_mm` / `size_y_mm` / `size_z_mm` | 외형 가로 / 세로 / 높이 | 3D를 실제 크기로 그림. WSH-01은 구역 크기 |
| `center_x_mm` / `center_y_mm` | 바닥 가운데 좌표 | 위 "좌표 읽는 법" |
| `facing` | 정면 방향 | `NEG_Y` (통로 쪽), **SAW-01만 `POS_X`(동쪽)** — 재료가 기계 뒤 → 앞으로 흐르고 투입 베드가 뒤(서쪽)에 붙음 |
| `size_source_tag` | 크기 근거 | SAW·VF-2 = `REAL`(제조사 자료 — SAW-01은 HCS-80 외형 도면 2,256 × 1,999 × 1,938, 정면이 동쪽이라 X = 깊이), MIL·CMM = `REFERENCE`(비슷한 모델 — MIL-01은 CMX 600 V 기본형 1,990 × 2,757), WSH = `VIRTUAL` |
| `ref_model` | 크기를 빌린 모델 | MIL-01 DMG MORI CMX 600 V, CMM-01 Hexagon TIGO SF, WSH-01 Kalamazoo KVF3급 + Branson CPX8800H-E급. **`model` 칸은 그대로 두고 크기만 빌림** |

출처: 설계서 5.1, ERD 5.A.2 표.

정비 때 잠금·표지를 거는 에너지 차단 지점이다. 작업지시서·지침카드의 안전 칸이 여기서 가져온다.

| 칸 | 뜻 | 값 |

공정 사이에 부품이 쌓이는 칸과 한도·경고 기준이다. 막힘(BLOCKED), 재공 경고, 병목 판단에 쓴다.

| 칸 | 뜻 | 값 |

| `from_process_code` / `to_process_code` | 앞 공정 / 뒤 공정 | → `process.csv` |

### `layout_object.csv` — 배치 물체 (11행)

설비가 아닌 바닥 위 물체다: 봉재 랙, 투입 대, 재공 자리 4곳, 온도 맞춤 선반, 완성품 자리, 통로, 문 2개.

| 칸 | 뜻 | 값 |
|---|---|---|
| `object_id` | ID | RACK-01, INF-01, WIP-1~4, SOAK-01, FG-01, AISLE-1, DOOR-1, EXIT-1 |
| `layout_id` | 공장 | `BLDG` |
| `object_kind` | 종류 | `MATERIAL_RACK` 봉재 랙, `INFEED` 투입 대, `WIP_SPOT` 재공 자리, `SOAK_SHELF` 온도 맞춤 선반, `FG_SPOT` 완성품 자리, `AISLE` 통로, `DOOR` 반입문, `EXIT` 비상구 (ERD 6.49) |
| `object_name` | 이름 | 화면에 보일 이름 |
| `x_min_mm` ~ `y_max_mm` | 바닥 사각형 범위 | 문은 벽 위라 X 시작 = X 끝 |
| `height_mm` | 높이 | 투입 대 925 [실제: HCS-80], 봉재 랙 2,000·온도 맞춤 선반 1,385 [참고: 제품 표준 높이], 문 2,600·2,000. 바닥 표시만인 것(재공 자리·완성품 자리·통로)은 빈칸 |
| `source_tag` | 근거 (크기·높이) | INF-01 `REAL`(HCS-80 배치도), RACK-01·SOAK-01 `REFERENCE`(실제 제품 치수), 나머지 `VIRTUAL`. 자리(좌표)는 모두 팀이 정함 |
| `buffer_code` | 재공 위치 | 재공 자리만. WIP-1 = WIP-10-20 … WIP-4 = WIP-40-50. **자리 ID와 재공 위치 코드는 다른 키** |

- 재공 자리는 보통 설비 사이 간격 앞에 있다. 다만 **WIP-2(OP-30에 들어갈 재공)와 WIP-3(OP-30에서 나온 재공)은 VF2-01·02 사이 앞에 800 mm 띄워 나란히** 둔다 (가공 전·후 상자가 섞이지 않게). OP-30은 두 대가 같은 재공에서 받고 같은 재공으로 보내는 병렬 공정이라, 한 대에서 나온 부품이 다른 한 대를 거치는 것처럼 보이지 않게 했다 (2026-10-10).
- **온도 맞춤 선반 SOAK-01은 CMM 앞 재공 띠**(Y 2,000~2,457)에 있다. 측정할 부품이 WIP-4 → 선반(90분 이상) → CMM으로 짧게 가게 했다. 작업 띠(Y 2,800~3,800)는 비워 둔다 (2026-10-10).
- **봉재 랙·온도 맞춤 선반 크기는 실제 제품 치수** (2026-10-10): 봉재 랙 3,814 × 720 × 2,000 = Hoffmann 외팔보 랙(한쪽 면, 깊이 600), 선반 1,219 × 457 × 1,385 = Metro 철망 선반 1848 + 기둥 54P. 둘 다 표준 높이 중 가장 낮은 것 (손으로 넣고 빼므로 어깨 위 들기를 피함, KOSHA A-G-17-2026). 자세한 근거: 3D 설비 규격 조사 10.6.

출처: ERD 5.A.9 표 (3D 설비 규격 조사 7장).

### `equipment_part_shape.csv` — 설비 부품 도형 (27행)

설비 하나를 여러 상자로 나눠 그릴 때의 부품 크기와 위치다. 2026-10-10에 SAW-01 7, MIL-01 4, VF-2 5 × 2를 더해 **27행**이다 (WSH-01 5, CMM-01 1은 그대로). 위치는 공식 도면(Haas HCS-80 외형 도면·VF-2 배치도, DMG MORI CMX V 카탈로그)에서 잰 값이라 `REFERENCE`이고 ±50 mm 정도 오차가 있다. 모르는 크기·위치는 비운다. 상대 위치는 **공장 축 기준**이다 (SAW-01은 정면이 동쪽이라 부품 X가 깊이 방향).

| 칸 | 뜻 | 값 |
|---|---|---|
| `equipment_id` / `shape_seq` | 설비 / 순번 | SAW-01 1~7, MIL-01 1~4, VF2-01·02 1~5, WSH-01 1~5, CMM-01 1 |
| `part_code` / `part_name` | 부품 코드 / 이름 | 예: WSH-01-T 진동 바렐 |
| `shape_kind` | 도형 | `BOX`, SAW-01 위 원통만 `CYLINDER` |
| `size_x_mm` / `size_y_mm` / `size_z_mm` | 크기 | 모르면 빈칸 |
| `offset_x_mm` / `offset_y_mm` | 설비 가운데에서 얼마나 떨어졌나 | 예: 진동 바렐 (−943, −307) |

- 기계 안쪽 부품(톱날, 테이블 등)은 3D에서 보이지 않아 넣지 않았다. 부품별 근거와 출처는 `docs/line/3D_설비규격/3D_설비규격_조사.md` 10장.

### `inspection_item.csv` — 검사 항목 (8행)

BRK-A100의 검사 항목과 기준(가상 도면)이다. 판정과 Cpk 기준이 여기서 나온다.

| 칸 | 뜻 | 값 |

| `item_name` / `spec_text` | 이름 / 기준 글 | 예: 부싱 압입 구멍 지름 / Ø45 H7 (+0.025 / 0 mm) |
| `nominal` / `lsl` / `usl` | 기준값 / 아래 / 위 한계 (mm) | 치수 항목만. 평면도는 위 한계 0.05만. 나사·외관은 빈칸 |
