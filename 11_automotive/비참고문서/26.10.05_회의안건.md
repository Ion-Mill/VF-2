## 안건 1. 교대가 바뀔 때 로트 번호를 새로 붙일지

**팀원에게 이렇게 말하면 된다**

> "로트 추적(PRD-05)에 관한 내용입니다. 지금은 작업지시 1건 = 로트 1개라서, 한 로트가 주간·야간 두 교대에 걸쳐 만들어질 수 있어요. 그런데 자동차 협력사 추적성 기준에는 '교대가 바뀌면 로트 번호를 바꾼다'는 규칙이 있습니다. 그래서 **로트 번호를 그대로 둘지, 교대가 바뀌면 나눌지** 정해야 하는데 어떤 게 좋을까요?"

**왜 정해야 하나**

- 로트 1개(평균 36개)가 라인을 다 지나가는 데 약 2~3시간 걸린다. 교대 끝나기 2~3시간 전에 시작한 로트는 다음 교대로 넘어간다.
- 우리 교대는 주간 08:00~17:00, 야간 20:00~05:00이라 **교대 사이에 3시간 라인이 멈춘다.** 즉 교대에 걸친 로트는 "멈췄다가 다시 시작"한다.
- 나중에 불량이 나왔을 때 "어느 교대·누가 만들었나"를 찾으려면 로트가 교대별로 나뉘어 있는 편이 쉽다.

**선택지**

|        | A. 그대로 둔다 (지금 설계)                              | B. 교대가 바뀌면 나눈다                                                                |
| ------ | ------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 방법   | 작업지시 1건 = 로트 1개. 교대가 바뀌어도 같은 번호      | 교대가 바뀌면 같은 작업지시 안에서 로트를 나눔. 예: `LOT-2609-001-A`(주간), `-B`(야간) |
| 장점   | 데이터·화면이 단순하다                                  | 자동차 협력사 기준에 맞다. 교대 보고서·불량 추적이 깔끔하다                            |
| 단점   | 불량이 나면 어느 교대 것인지 공정 기록을 따로 봐야 한다 | 로트 표·추적 화면이 조금 복잡해진다 (작업지시 1 : 로트 N)                              |
| 작업량 | 없음                                                    | 데이터·ML(생성기), 백엔드(로트 테이블), 프론트(로트 추적 화면) 조금씩 늘어남           |

**관련 자료**

| 문서 (위치)                                                                                                                  | 쪽            | 내용                                                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Panasonic 부품 추적성 요구사항 (`docs/production/로트추적_IATF/Panasonic_PIDEU_parts_traceability_requirements_v2_2022.pdf`) | 7쪽 §6.3      | "로트 단위 제품은 다음 경우에 로트 번호를 바꾼다: a) 공정 재시작 b) **교대 변경** c) 생산일 변경 d) 한 교대 안의 긴 휴식"                                                   |
| 같은 문서                                                                                                                    | 12쪽 (점검표) | "어떤 이유로 로트 번호를 바꾸는가?"를 공급사 점검 질문으로 묻는다. 추적할 정보: 하위 부품 로트, 사용한 공구·설비, 검사 결과·공정 조건                                       |

## 안건 2. 공구 수명을 무엇으로 셀지

**팀원에게 이렇게 말하면 된다**

> "공구 수명·재고(ML-01, INV-01)에 관한 내용입니다. 지금은 '부품 1개를 깎으면 공구 사용 1회'로 세는데, Haas 기계는 실제로 공구별로 **구멍 수**나 **절삭 시간**으로도 셉니다. 탭은 부품 1개에 구멍이 여러 개라서 지금 방식이면 수명이 실제와 크게 달라질 수 있어요. **'부품 1개 = 1회'로 둘지, Haas 방식(구멍 수·이송 시간)으로 바꿀지** 정해야 하는데 어떤 게 좋을까요?"

**왜 정해야 하나**

- 지금 가상 한도는 "탭 400회, 엔드밀 800회"(부품 수 기준)다.
- 그런데 부품 1개에 M6 나사 구멍이 4개라면, 탭은 부품 400개 = **구멍 1,600개**를 뚫는 셈이다. 알루미늄 M6 탭 자료는 수백 구멍 수준이라 수명이 과하게 길어진다 (이상혁 조사).
- 공구 교체 시점이 바뀌면 교체 알림, 재고 차감, 불량 증가 시점(공구 수명 90% 이후)도 같이 바뀐다.

**선택지**

|        | A. 부품 1개 = 1회 (지금 설계)                            | B. Haas 방식으로 공구마다 다르게                                                   |
| ------ | -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 방법   | 모든 공구를 "부품 몇 개 깎았나"로 셈                     | 탭·드릴·보링 = **구멍 수**(HOLES), 엔드밀·페이스밀 = **이송 시간**(FEED, 분)       |
| 장점   | 단순하다. 데이터 만들기 쉽다                             | Haas 실제 화면(고급 공구 관리)과 같다. 수명 근거가 더 정확하다                     |
| 단점   | 탭처럼 부품당 여러 번 쓰는 공구는 수명이 실제와 어긋난다 | 부품 1개당 구멍 수·이송 시간을 정해야 한다 ([가상] 값). 한도 값도 다시 정해야 한다 |
| 작업량 | 없음 (한도 값만 낮추면 됨)                               | 데이터·ML(생성기 공구 기록), 화면(공구 수명 표시 단위) 조금 늘어남                 |

- 절충안: 단위는 A로 두고, **탭 한도만 구멍 수에 맞게 낮추는** 방법도 있다 (예: 탭 400회 → 100회 = 구멍 400개).
- ML-01 예측 모델은 어느 쪽이든 실제 Haas VF-1 실험 데이터(사이클 수 기준)로 학습하므로 영향이 없다.

**관련 자료**

| ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Haas 밀 조작 매뉴얼 한국어판 (`docs/haas/ko_96-KO8210_Mill.pdf`)                                                               | PDF 133~134쪽 (인쇄 111~112쪽), 4.9.2 고급 공구 관리 | 공구 수명 한도 칸: "**USAGE** – 공구를 만료 전에 사용할 수 있는 최대 횟수", "**HOLES** – 만료 전 공구가 뚫을 수 있는 최대 구멍 수", "**FEED** – 공구가 이송 상태에 있을 수 있는 총 시간(분)", "WARN – 경고 메시지를 보내기 전 남은 수명의 최소값" |

## 안건 3. OP-50 검사를 전수로 둘지, 발췌로 바꿀지

**팀원에게 이렇게 말하면 된다**

> "품질 검사(QLT-01)와 병목 시연에 관한 내용입니다. 지금은 OP-50에서 **모든 부품을 측정(전수)**하는데, 실제 양산에서는 3차원 측정기로 전수 검사하는 경우가 드물고 **일부만 뽑아 검사(발췌)**하는 경우가 많다는 의견이 있었어요. 다만 발췌로 바꾸면 '검사 강화로 병목이 옮겨 가는' 시연 장면이 달라집니다. **전수로 둘지, 평소엔 발췌 + 의심 로트만 전수로 할지** 정해야 하는데 어떤 게 좋을까요?"

**왜 정해야 하나**

- 정현숙 조사: "양산에서 CMM 전수는 흔치 않다. 다만 이를 뒷받침하는 수치는 찾지 못함" → 발췌 + 의심 로트 전수 옵션을 권고.
- 자동차 협력사 품질 기준(Nemak)은 "**공정능력(Cpk)이 기준에 못 미치면 기준을 맞출 때까지 전수 검사**"라고 한다. 반대로 말하면 공정이 안정적이면 발췌가 허용된다.
- 이 결정은 시연 2막(충돌 → 의심 로트 → 검사 강화 → OP-50 병목)에 바로 영향을 준다.

**선택지**

|                | A. 전수 유지 (지금 설계)                         | B. 평소 발췌 + 의심 로트 전수                                                     |
| -------------- | ------------------------------------------------ | --------------------------------------------------------------------------------- |
| 평소           | 모든 부품 측정, 1개당 2.5분                      | 로트의 첫 부품 + N개마다 1개 측정. 나머지는 육안·통과정지 게이지만                |
| 검사 강화      | 의심 로트의 측정 항목을 늘려 1개당 2.5 → 5.0분   | 의심 로트를 **전수로 바꿈** (발췌 → 전수)                                         |
| 병목 이동 시연 | 지금 그대로 가능                                 | 가능. 오히려 "발췌 → 전수 전환"이 실제 기준(Nemak, MIL-STD)과 맞아 설명이 더 쉽다 |
| 장점           | 단순하다. 부품마다 측정값이 있어 Cpk 계산이 쉽다 | 현실에 가깝다. 검사 강화의 근거가 분명하다                                        |
| 단점           | "실제로는 전수 안 한다"는 지적을 받을 수 있다    | 측정하지 않은 부품은 측정값이 없다. 발췌 비율(N)을 [가상]으로 정해야 한다         |
| 작업량         | 없음                                             | 데이터·ML(검사 결과 생성), 품질 화면(발췌·전수 표시) 조금 늘어남                  |

**관련 자료**

| 문서 (위치)                                                                  | 쪽                   | 내용                                                                                                                                                                                 |
| ---------------------------------------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Nemak 협력사 품질 매뉴얼 (`docs/quality/협력사_판정기준/nemak_sqm_2023.pdf`) | 16쪽                 | "공정능력 기준(고객 지정 특별 특성 Cpk 1.67, 공정 중요 특성 1.33)을 못 맞추는 공정은 기준을 맞출 때까지 **100% 검사**해야 한다. 100%보다 적은 샘플링 계획은 서면 승인을 받아야 한다" |

| 정현숙 BENCHMARKS (`analysis/생산_프로파일링/BENCHMARKS.md`)                 | 135행                | "OP-50 2.5분 전수: 단순 브래킷이라 가능하지만 양산 CMM 전수는 흔치 않음(수치 못 찾음) → 초물·N개마다 발췌 + 전수는 의심 로트에 한정, 시연 S1과 일관되게"                             |
| 가상데이터설계서\_v2                                                         | 5.15, 5.18 ③, 7장 S1 | 지금 규칙: 전수 측정, 검사 강화 때 2.5 → 5.0분, 병목이 OP-50으로 이동                                                                                                                |

## 안건 4. 정비 기능을 VF-2만 할지, 다른 공정까지 할지

**팀원에게 이렇게 말하면 된다**

> "정비 기능(MNT-02~05)의 범위에 관한 내용입니다. 지금 지침카드·작업지시서·작업기록서·예방 정비는 사실상 OP-30의 **Haas VF-2 2대** 기준으로 되어 있어요. 다른 공정(절단기, 황삭기, 세척기, 측정기)까지 넣으면 더 '라인 전체'처럼 보이지만, 자료와 작업이 늘어납니다. **VF-2만 할지, 다른 공정도 간단히 넣을지** 정해야 하는데 어떤 게 좋을까요?"

**왜 정해야 하나**

- 2D 디지털 트윈은 5개 공정을 다 보여 준다. 그런데 다른 공정에서 고장이 나면 무엇을 보여 줄지가 아직 비어 있다.
- 시작 알람 15개는 모두 Haas NGC(VF-2) 알람이다. 다른 공정을 넣으면 Siemens(OP-20)·HCS-80(OP-10) 알람 자료로 사내 문서를 더 만들어야 한다.
- 3주 일정에서 정비 담당과 AI 비서 담당의 작업량이 달라진다.

**선택지**

|                                | A. VF-2만 (정비 기능 전체)                       | B. VF-2는 깊게 + 다른 공정은 간단히                             |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------- |
| 지침카드·작업지시서·작업기록서 | VF-2 알람만                                      | VF-2 알람 + 다른 공정 알람 공정당 2~3개                         |
| 예방 정비                      | VF-2 정비 일정(Haas 58항목 중 기본 사양)만       | + 다른 공정 점검 몇 개 (예: 측정기 중간 점검, 바렐 그리스 주입) |
| 다른 공정이 멈추면             | 화면에 "정지"와 정지 사유만 표시, 지침카드 없음  | 간단한 지침카드 표시                                            |
| 장점                           | 자료가 충분하고 근거가 탄탄하다. 일정이 안전하다 | 라인 전체 운영 플랫폼이라는 인상이 강하다                       |

- 기획서 1.5는 이미 "알람 카드는 OP-30을 깊게, 나머지는 얕게"라고 적어 두었다. B를 고르면 이 문장대로 하는 것이고, A를 고르면 "나머지는 상태·실적만"으로 고친다.
