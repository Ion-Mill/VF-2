# 패키지 변경 기록 (설치·수정·제거) — 2026-10-25

> **이 문서 하나만** 패키지(파이썬 `pip`, 화면 `npm`)를 설치·수정·제거할 때마다 고친다. 새 파일을 따로 만들지 않고, 옛 날짜 파일도 남기지 않는다.
>
> **고치는 법**: ① 아래 3장 표에 한 줄을 더한다 (위가 최신) ② 1·2장이 바뀌었으면 같이 고친다 ③ **파일 이름의 날짜를 그날로 바꾼다** (`패키지_변경기록_YYYYMMDD.md`) ④ 이 파일 이름을 적은 곳(`파일설명.md`, 그날 `구현_중_수정사항/MMDD_수정간단내용.md`)도 같이 맞춘다.
>
> 패키지를 **적는 곳은 각 `requirements.txt`**(파이썬)와 `package.json`(화면)이다. 이 문서는 "언제 무엇을 왜 바꿨나"를 모아 둔 기록이다. 이 PC에서 `npm install`·`npm ci`·`npm update`는 사용자가 시킬 때만 한다.

- 가상환경은 서로 다르다. 같은 이름의 패키지도 환경마다 버전이 다를 수 있다 (예: `psycopg` — 백엔드 3.2대, 비서 3.3.6, 생성기 3.2.13).
- 새 PC에서 준비: 각 폴더의 `.venv`를 만들고 `python -m pip install -r <그 환경의 requirements.txt>`. Windows에서는 `PYTHONUTF8=1`을 먼저 준다 (`requirements.txt`의 한글 주석을 pip가 cp949로 읽다 실패한다).
