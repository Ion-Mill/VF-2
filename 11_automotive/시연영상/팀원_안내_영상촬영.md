## 2. 설치

앱(화면·백엔드·비서)은 이미 돌아가는 상태여야 한다. 아래는 **영상 도구에만** 필요한 것이다.

| 필요한 것 | 설치 방법 | 확인 |
|---|---|---|
| Node.js | 앱 화면용으로 이미 설치되어 있음 | `node -v` |
| Microsoft Edge | Windows 기본 | — |
| ffmpeg | `winget install Gyan.FFmpeg` 후 **새 터미널** | `ffmpeg -version` |
| Docker Desktop | 영상용 로컬 DB용 (켜 둔다) | `docker ps` |
| 도구 패키지 | `cd 11_automotive/시연영상` → `npm install` | `node_modules/playwright` 생김 |
| 음성 만들기 | `cd 11_automotive/시연영상` → `python -m venv .venv` → `.venv\Scripts\pip install edge-tts` | `.venv\Scripts\python -c "import edge_tts"` |
| 앱 쪽 환경 | `frontend`는 `npm install`(자막 글꼴 Pretendard도 여기서 옴), `backend`·`assistant`·`생성기`는 각자의 `.venv`에 `requirements.txt` 설치 | `패키지_변경기록_20261025.md` 참고 |
| 비서(LLM) 키 | `assistant/.env`에 Claude 키가 있어야 이브 채팅이 답한다. **키는 영상 담당에게 따로 받는다 — 절대 커밋하지 않는다** | — |

- 나레이션 음성은 Microsoft(edge-tts)를 쓰므로 **인터넷이 필요**하다. 보내지는 글은 가상 시연 문장뿐이다.
- 목소리는 **여성 SunHi, 속도 +25%** 로 확정했다 (`tools/lines.py`).

## 4. 돌리는 순서

모두 `11_automotive/시연영상`에서 실행한다.

**처음 한 번 (영상용 로컬 DB 만들기)**

| 순서 | 명령 | 설명 |
|---|---|---|
| 1 | `.venv\Scripts\python 로컬DB\make_local_env.py` | `backend/.env.local-video`를 만든다 (로컬 DB 전용 무작위 비밀번호, `assistant/.env`의 비서 키를 읽음). 깃에 안 올라간다 |
| 2 | `docker network create mom-video-net` / `docker volume create mom_video_pgdata` | |
| 3 | `docker build -t mom-backend-loader ../backend` | 데이터 적재 도구 이미지 |
| 4 | `bash 로컬DB/reload_video_db.sh` | DB 컨테이너를 만들고 영상용 데이터(10/1~10/23 기록)를 넣고 시계를 10/24 09:00에 맞춘다 |

**촬영할 때마다**

| 순서 | 명령 | 설명 |
|---|---|---|
| 1 | `powershell -File 로컬DB\start_video_local.ps1` | 백엔드 8000 · 비서 8100 · 시연 서버 8765 · 화면 3000을 켠다 (DB 5433). **같은 포트를 쓰는 개발 서버는 꺼 둔다** |
| 2 | `.venv\Scripts\python tools\lines.py` | 나레이션 음성 만들기. 문구를 바꿨을 때만 (`--force`면 전부 다시) |
| 3 | `node tools\subs.js` | 자막 그림 만들기 |
| 4 | `node tools\record.js` | **자동 촬영** (약 6분). 시연 시계를 10/24 09:00으로 되돌리고 시작한다. 촬영 중에는 서버·노트북을 건드리지 않는다 |
| 5 | `.venv\Scripts\python tools\edit.py 시연영상_v5.mp4` | 편집(자르기·배속·음성·자막·제목·페이드) → mp4. 약 15초. 길이만 보려면 `--plan` |
| 6 | `powershell -File 로컬DB\stop_video_local.ps1` | 다 끝나면 끈다 (DB 컨테이너는 그대로) |

문구나 자막 모양만 고칠 때는 영상을 다시 찍지 않고 **2 → 3 → 5**만 다시 돌린다.

## 6. 알아 둘 것

- **길이 줄이기(4:36 → 4:15) 후보**: 계정 소개 한 마디 5줄의 음성 빼기(자막은 유지, 약 18초) / 일일 보고서 두 줄 합치기(약 4초) / 말없는 화면 이동 줄이기. 어느 쪽으로 줄일지는 영상 담당과 정한다.
- **아쉬운 곳**: 재고 "오늘 사용" 박스가 작음, 병목 장면의 재공 박스 크기, 안전 칸 박스가 낱말보다 늦게 따라옴, 몇몇 박스가 낱말보다 1~3.6초 늦음 (s7a "야간 교대 시작" 등). 자세한 건 `수정내용_v4_20261025.md`.
- **연음 표기**: 읽는 소리(`tts`)에서 연음을 소리 나는 대로 고치는 일은 아직 안 했다. 어색하게 들리는 줄은 `lines.py`의 `tts`만 고쳐 다시 만든다.
- **비서 질문**: 로컬 DB를 쓰므로 채팅 질문이 공용 DB에 남지 않는다. 대신 Claude 키가 있어야 답이 나온다. 마이크(음성 입력)는 쓰지 않는다.
- **최종 발표 서버와 별개**: 영상용은 `.env.local-video`(로컬), 발표용은 `.env.supabase`(공용)다. 영상 촬영에 `.env.supabase`를 쓰지 않는다. 발표 서버는 월요일 15:00 전에 따로 켜고, 발표 중에는 재시작하지 않는다.
- **비밀값**: `.env*`, 키, 비밀번호는 커밋하지 않는다. 이 폴더의 스크립트에는 비밀값이 없다.
- 막히면 `로컬DB/run/*.log`(서버 로그)를 먼저 본다. 화면이 안 뜨면 포트(3000·8000·8100·8765·5433)가 이미 쓰이고 있는지 확인한다.
