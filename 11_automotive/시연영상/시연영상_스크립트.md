## 3. 자막·음성을 영상에 입히는 방법

1. 촬영 스크립트가 각 동작 직전·직후의 **원본 시각**을 기록한다 (`timeline.json`: 장면·동작·시작·끝).
2. 나레이션 줄마다 음성 파일을 만들고 **길이를 잰다**.
3. 컷 길이를 `max(동작 시간 ÷ 배속, 음성 길이 + 0.4초)`로 정한다. 합계가 4:58을 넘으면 배속 구간의 배속을 올려 맞춘다. 줄여도 안 맞으면 해당 문구를 줄인다 (자동으로 경고).
4. 배속 후 시각 기준으로 **자막 파일(`시연영상.srt`)** 과 **음성 배치표**를 만든다.
5. `ffmpeg`로 화면 배속 → 음성 입히기 → 자막 입히기(하드 자막) → 합치기.
6. 문구·모양만 고칠 때는 영상을 다시 찍지 않고 2~5번만 다시 돌린다.

화면에 자막을 직접 그려서 녹화하면 배속 때 자막이 같이 빨라지므로, 자막은 배속한 **뒤**에 입힌다.

## 4. 자막·커서·강조 박스 규칙

**자막**

| 항목 | 정함 |
|---|---|
| 위치·모양 | 화면 아래 가운데, 반투명 검정 띠(투명도 66%, 모서리 둥글게) + 흰 글자(굵게, 맑은 고딕), 글자 높이 40px(1080p), 아래에서 90px 띄움. 홈 하단 패널(생산·예측·OEE)이 보이는 컷은 띠를 패널 **위**(위에서 약 612px)로 올려 패널을 가리지 않게 한다. 시안: `시연영상/자막시안/자막시안_3D.png`, `자막시안_홈패널.png` |
| 줄 수 | 최대 2줄, 한 줄 22자 안쪽. 문장이 길면 쉼표·"~고" 자리에서 나눔 |
| 시간 | 음성 줄이 나오는 동안 보이고, 끝나면 0.2초 뒤 사라짐 |
| 강조 | 핵심 낱말(선제 알림·규칙·출처·승인·확정)만 노란색 |
| 장면 사이 | 0.3초 페이드. 장면 번호·제목 자막은 넣지 않는다 |
| 화면 표시 | 계정 전환 칩·동작 설명 칩 같은 **덧붙임 표시는 넣지 않는다**. 계정 전환은 나레이션 안에서 말한다 |

**마우스 커서 = 이브 얼굴 + 한 손**

| 항목 | 정함 |
|---|---|
| 모양 | 앱의 이브(3D 모델)에서 뽑은 **얼굴 + 한 손만** (몸통·반대쪽 손 없음), 손은 **두껍게**, 얼굴 왼쪽 위에 닿을 듯 말 듯 **얼굴보다 높게** 든 모습이고 **손끝은 파랑 그라데이션**(안쪽 색과 외곽선이 같이 손끝 파랑 → 뿌리 남색으로 이어짐). 그림은 이미지 생성 없이 같은 모델로 만든다 (평소 1장, 클릭 순간 1장 — 클릭 때는 손이 내려오고 얼굴이 살짝 숙임) |
| 크기 | 작게 (약 56px). 손끝이 잘 안 보이면 손끝에 파스텔 블루 링을 겹친다 |
| 클릭 지점 | **손가락 끝** (그림의 핫스팟). 클릭하면 손이 살짝 내려가고 링이 한 번 퍼진다 |
| 이동 | 직선이 아니라 0.4~0.8초 곡선, 클릭 전 0.3초 멈춤 |
| 시안 | **시안 1장을 먼저 보고 승인받은 뒤** 쓴다. 승인 전까지는 임시로 파스텔 블루 링 커서 |
| 하지 않는 것 | 이브 얼굴이 화면 곳곳을 떠다니며 가리키는 연출 (컷 시간이 늘고 화면을 가림) |

**강조 박스** (설명하는 곳에 시선이 가도록)

| 항목 | 정함 |
|---|---|
| 모양 | 진한 파랑 둥근 테두리(약 3px) + 흰 바깥선, 천천히 숨 쉬듯 굵기가 변함. **글자는 달지 않는다** (테두리만) |
| 색 | 진한 파랑. 앱의 긴급 빨강·주의 노랑과 겹치지 않고, 파스텔 블루 배경에서도 묻히지 않는다 |
| 표·카드·보고서 | 박스 바깥을 35% 어둡게(스포트라이트) |
| 3D | **테두리만** (어둡게 하면 흐름이 안 보임) |
| 타이밍 | 그 설명 문장이 시작되기 0.2초 전에 켜지고, 다음 대상으로 넘어갈 때 부드럽게 옮겨 감 |
| 지정 | 컷표의 "강조" 칸에 대상을 적는다 (화면 요소 이름으로 찾음). 영상용 덧그림이라 앱 코드는 건드리지 않는다 |

## 7. 촬영·제작 방법 (자동 구성)

| 순서 | 할 일 | 비고 |
|---|---|---|
| 1 | 촬영용 스크립트 하나(`Playwright`)가 브라우저를 열고 위 컷표대로 마우스를 움직인다 | 이동·클릭 규칙은 4장 |
| 2 | 마우스 커서(이브 얼굴 + 한 손)와 강조 박스를 영상용으로 화면에 덧그린다 (앱 코드는 건드리지 않음) | 박스는 컷표의 "강조" 칸 대상을 화면 요소 이름으로 찾아 그린다 |
| 3 | 브라우저 창 1920×1080으로 녹화(`recordVideo`) | 소리 없음 |
| 4 | 동작 사이 시각을 `timeline.json`에 기록 | 3장 |
| 5 | 나레이션 줄마다 음성 파일을 만들고 길이를 잼 | 2장 |
| 6 | 편집: 구간별 배속 → 음성·자막 입히기 → 합치기(`ffmpeg`) | 3장 |
| 7 | 리허설 촬영 1회 → 문제 컷만 고쳐 다시 촬영 → 본촬영 | 각 촬영 전 [처음으로](10/24 09:00) |

**설치 상태 (2026-10-23 완료)**: `ffmpeg` 9.0.2 풀 빌드(winget `Gyan.FFmpeg` — 새 터미널을 열어야 PATH에 잡히고, `tools/`가 PATH와 winget 기본 위치에서 `ffmpeg`·`ffprobe`를 찾는다), `Playwright` 1.64.1(Node, `시연영상/`), `edge-tts` 7.3.1(`시연영상/.venv`). 브라우저는 이 PC에 이미 있는 **Edge**(`msedge`)로 녹화할 계획이라 브라우저 다운로드는 하지 않았다. 설치는 모두 `시연영상/` 안에서만 했고 앱 폴더는 건드리지 않았다. 폴더: `tools/`(도구), `목소리샘플/`, `커서시안/`.

앱 쪽 주의:
- 시연 서버가 만드는 사건은 DB에 들어가지 않지만, **채팅 질문은 공용 DB(`chat_log`·`access_log`)에 남는다**. 리허설 때 같은 질문을 여러 번 보내지 않는다.
- **S1 충돌은 정지 등급 992 한 건만 뜬다** (2026-10-23 수정, 예전에는 108 → 994 → 992 세 건). 그래서 장면 4에는 "알람 세 개를 묶어 충돌로 판단"하는 설명이 없고, 카드의 원인·조치 문구와 3D 흐름을 보여 준다. 시연 서버를 다시 켠 뒤에 촬영한다.
- 사건 버튼은 "대상 설비 가공 중 아님", "진행 중 사건 있음"이면 흐려진다. 362 뒤 VF2-01이 다시 가동될 때까지 시계를 흘린다 (장면 3 촬영 메모).
- 외부 Claude(문장 다듬기)가 켜진 상태에서만 5·6·7장면의 다듬은 문장이 나온다. 시연 서버와 비서가 이미 켜져 있어야 한다.
- 이브 말풍선은 **이브 창(사이드바)이 열려 있으면 보이지 않고**, 문서 말풍선이 2건 이상이면 "확정·검토할 문서 N건"으로 나와 알림 탭을 한 번 더 거쳐야 한다. 말풍선으로 들어가는 컷은 사이드바를 닫은 상태에서 시작한다.
- 홈 알림 띠는 **홈 화면에서만** 뜬다. 다른 화면에서는 긴급 알림이 이브 말풍선으로 나온다.
