## 2. 새로 확정할 수 있는 코드·구조

## 3. 쓰지 말 것

- `data/kamp/mirror_chakihwan`: umich 사본이라 사용 금지
- umich, mtconnect 데모: 생산 파트에 쓸모없음
- 블로우 성형 라인(`other_oee`): 불량률 4.9%라 불량 기준 부적합 (교대 보고 칸과 정지 원인 6분류만 참고)
- 4TU 보고유형 B의 "고장" 해석: 휴식인지 고장인지 구분 불가

## 4. 끝내 근거가 없어 "가정값"으로 표시할 것

공정 사이클타임(OP-20·30 포함), VF-2 알람 빈도, DOWN 비율과 정지 30~180분, MTBF·MTTR 대표값, 세척·텀블링 배치 크기, CMM 측정 시간과 전수/발취 비율, 일 생산량·납기·인수인계 시간, 공구 마모 드리프트 속도.

## 5. 한계

- 4TU는 2012년 소량 다품종 정밀부품 기록이라 분포의 모양만 참고합니다.
- NIST는 사실상 2개 설비·2일치라 전이확률과 알람 비율은 초깃값 수준입니다.
- Haas 표본은 선반(ST-40) 시험 운전 기록이고 PartCount 항목이 없습니다.
- 외부 수치 대부분이 검색 요약이고, 업체 블로그 출처가 많아 신뢰도가 낮습니다.
