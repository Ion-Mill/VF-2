# CLAUDE.md

## 프로젝트

AI 운영 비서 기반 자동차 부품 절삭가공 라인 운영 관리 플랫폼(MOM)의 폴더다. 기획으로 시작해 지금은 **구현이 끝나고 마무리하는 단계**(2026-10-27)다. 코드는 `backend/`(서버·DB), `frontend/`(화면), `assistant/`(AI 비서), `생성기/`(가상 데이터·시연 서버), `deploy/`(배포)에 있고, **문서를 고칠 때는 코드가 기준이다** — 문서와 코드가 다르면 코드를 먼저 확인하고 문서를 맞춘다(코드가 앞선 설계 내용은 지우지 않고 [백엔드 미구현]처럼 표시). 이 폴더의 문서 작업 대상은 아래 표의 문서와 **가상 사내 문서 세트**(`가상사내문서/`)다. 2026-10-06 문서 검토 회의 결정을 반영해 모든 문서를 **최종본**으로 정리했다 (2026-10-07, 회의 결과 요약: `26.10.06_회의결과_수정사항.md`).

**기술 선택(구현 기준, 2026-10-27):** 화면 Next.js 14·React 18·three.js, 서버 FastAPI(SQLAlchemy·psycopg), DB PostgreSQL 16(서버는 공용 Supabase), 실시간 SSE(`LISTEN/NOTIFY`), 배포 Docker Compose + AWS 한 대(Caddy). AI 비서는 **외부 LLM(Claude) 하나**(채팅 앱은 Anthropic API, 호출 실패 때만 Gemini 대체 1회 — 2026-10-17·10-23·10-24)이고, 보내도 되는 자료의 범위는 요구사항 NFR-SEC-08이다. 표의 근거는 기획서 12.2. 코드로도 정해지지 않은 값(모니터 크기, 보관 기간 뒤 삭제 방식, 성능 목표, 합격 기준값)만 [선택 필요: 기술 회의]로 남겨 두고 문서를 쓰는 AI가 임의로 정하지 않는다. JSON은 설정 파일·비서 도구 호출 입출력·시뮬레이터 사건 넣기에 쓰고, 운영 데이터 저장은 DB로 한다.

- 최종본을 크게 고칠 때는 팀과 상의한 뒤 새 파일을 만들고, 이전 파일 맨 위에 "이전 버전입니다" 줄을 넣는다. 작은 수정은 최종본을 바로 고치고 그 문서의 개정 기록에 남긴다.
- 가상 사내 문서는 파일 이름을 바꾸지 않고 개정 번호(Rev.0 → Rev.1 …)로 관리한다.
- 파일 이름은 한국어로 짓는다.
- **팀 전달 뒤 수정 기록:** 폴더를 팀에 전달한 뒤(2026-10-08~)에 바뀌는 내용은 `구현_중_수정사항/MMDD_수정간단내용.md`(예: `1008_수정간단내용.md`)에 핵심만 짧게 정리한다. 같은 날 수정은 같은 파일에 더한다.
- 가상 사내 문서(`가상사내문서/`)는 `가상데이터설계서` 13장 제작 기준과 `가상사내문서/00_용어집.md`를 따른다. 문서마다 표지(문서 번호·개정·"가상 사내 문서" 표시)와 항목별 출처([실제]/[참고]/[가상])를 붙인다.

## 필수 규칙: 파일설명.md 갱신

**어떤 요청이든, 그 작업으로 이 폴더 안에 파일·폴더가 새로 생기거나, 내용이 추가되거나, 삭제·이름 변경되면 같은 작업 안에서 `파일설명.md`를 고친다.**

- 해당 파일·폴더의 설명 줄을 추가·수정·삭제한다.
- 맨 아래 "변경 기록" 표에 날짜, 파일, 변경 내용을 한 줄 추가한다.
- 기존 문서의 내용만 고친 경우에도, 그 문서의 설명(버전, 주요 내용)이 바뀌었으면 고치고 변경 기록에 남긴다.
- `파일설명.md` 자신을 고친 것은 변경 기록에 남기지 않는다.

## 문서 작성 규칙

- 한국어로, 쉬운 말로 쓴다. 표를 많이 쓴다.
- 표시 규칙: **[실제]** 공개 문서·데이터 그대로 / **[가상]** 팀이 정한 값 / **[참고]** 다른 회사·산업 값의 모양만 빌림 / **[제안]** / **[선택 필요]**
- 근거 없는 숫자(알람 기준 온도 등)는 만들지 않는다.
- AI가 만든 문서 초안은 **"AI비서 초안"** 이라고 부른다.
- 원문(Haas, Siemens 매뉴얼 등)과 그 번역본은 저작권 때문에 공개 저장소에 올리지 않는다. 단, 사내문서는 가능함.
- 숫자(API 수, 시험 수, 테이블 수 등)를 문서에 적을 때는 코드·시험 결과로 센 값만 쓰고, 센 날짜를 같이 적는다.
