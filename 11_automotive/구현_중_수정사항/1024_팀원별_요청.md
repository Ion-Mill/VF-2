## 4. 주고받는 값의 모양 (초안 — 바꾸면 알림)

**시연 서버 `GET /api/health`에 추가되는 필드**
```
"profile": "video" | "final",
"clock_mode": "accelerated" | "wall",
"controls": { "visible": [...], "hidden": ["event","pause","recover","speed","skip","reset"] },   // hidden은 ?dev=1일 때만
"shift": { "DAY": {"start":"09:00","end":"18:00"}, "NIGHT": {"start":"21:00","end":"06:00"} },
"history_end": "2026-10-25",
"live_start": "2026-10-26T15:00:00+09:00"
```
**프로필 파일 `생성기/profiles/<이름>.json`**: `name`, `history_end`, `scripted_until`(최종용 10/26 15:00), `live_start`, `clock`("accelerated"|"wall"), `out_dir`, `db_target`("local"|"shared"), `controls`.
**환경변수**: `MOM_PROFILE`(video|final), `MOM_ALLOW_SHARED_WRITE=1`(최종용 공용 DB 쓰기 확인), `MOM_PRETEND_NOW`(시험용 가짜 현재 시각), 기존 `MOM_DB_RELAY_URL`·`MOM_INGEST_KEY`.
**DB 새 표**: `demo_meta(profile PK, history_start, history_end, scripted_until, live_start, seed, generated_at)`, `live_owner(id=1 PK, owner, host, profile, last_beat)`.
**형식**: 날짜 `YYYY-MM-DD`, 시각 ISO 8601 `+09:00`(KST), 교대 시각 `HH:MM` 24시간, `shift_id`는 그대로(`YYYY-MM-DD-D|N`, 야간은 시작일 기준).

> 서버는 **AWS 리눅스 + 도커**에 올리고, 평가자가 **문서 열람 + 이브 채팅**(마이크 한두 번)을 해요.
> **부탁**: ① **음성 입력**: `ASSISTANT_VOICE=1`일 때 모델(`large-v3-turbo`, CPU int8)이 서버에서 얼마나 걸리는지, 느리면 `VOICE_MODEL=small`로 낮춰도 되는지, 도커 이미지에 모델을 **미리 받아 넣는 방법**을 알려 주세요(서버 사양 `t3.xlarge`) ② 비서가 날짜·`MOM_PROFILE`을 하드코딩하고 있는지, 새 데이터(10/1~10/25 + 10/26 사건)로 질문했을 때 정상인지(예: "오늘 충돌 어땠어?") 확인 ③ 외부 Claude 계정의 사용 한도·비용 상한 ④ 비서 시험 8개 실패(10/22 "상태 되묻기" 변경 쪽)는 발표 전에 정리할지 판단해 주세요.
> 서버 시험 배포는 오늘 21시쯤(DB 담당과)이고, 일요일 오전에 새 버전으로 비서까지 확인해요.

### 그 외 팀원 (확인 요청)
> 일요일 오후에 **한두 분만** 최신 `main`을 받아 `-Profile final`(로컬 DB)로 켜서 화면이 뜨는지 확인 부탁드려요. 로컬 DB 설정은 `backend/.env.local-final.example`을 복사해서 쓰고, 안내는 제가 드려요. (전원이 하실 필요는 없어요.)

### 나 (데이터·문서)
2장(G1~G6) 진행 → 오늘 안에 깃에 올림 → 알림. 이어서 `deploy/`(서버 도커 묶음·안내서), 문서의 날짜·시각 정리(발표에 쓰는 핵심 문서 먼저), 일요일 G7과 합치기 확인.

## 7. 모두가 지킬 규칙

- 서버·공용 DB에는 **`git pull`로만** 반영한다(서버에서 직접 수정 금지).
- 비밀 값(`.env*`)은 깃에 올리지 않는다. 서버에서는 각자 직접 입력한다.
- 일요일 14:00 합치기 마감 이후에는 **버그 수정만**, 새 기능은 넣지 않는다.
- 바꾼 값의 모양(4장)은 임의로 바꾸지 않고 이 문서에서 알린 뒤 바꾼다.
