## 4. 주고받는 값의 모양 (초안 — 바꾸면 알림)

**시연 서버 `GET /api/health` (실제로 만든 모양, 2026-10-24)**
```
{ "ok": true, "run_id": 1792994400,
  "clock": { "sim_at": "...", "speed": 1, "paused": false, ..., "wall_now": "..."(실제 시각 모드일 때만) },
  "llm_compose": {...},
  "profile": {
    "name": "video" | "final",
    "clock_mode": "accelerated" | "wall",
    "controls": ["speed","pause","skip","buttons","reset"]  (영상용) | [] (최종용: 조작 없음),
    "history_start": "2026-10-01", "history_end": "2026-10-23" | "2026-10-25",
    "scripted_from": null | "2026-10-26T09:00",
    "live_start": "2026-10-24T09:00" | "2026-10-26T15:00",
    "pretend": false,
    "shifts": { "DAY": {"start":"09:00","end":"18:00","break":["13:00","14:00"]}, "NIGHT": {"start":"21:00","end":"06:00","break":["01:00","02:00"]} },
    "daily_report_latest": "07:00" } }
```
**최종용(`clock_mode: "wall"`) 시연 서버**: `POST /api/sim/clock·inject·fire` 등 시계·사건 조작은 **403**. 발표자 전용 하나만 — `POST /api/sim/reset`(처음으로, 시각은 그대로·사람 조작 지움·`run_id` +1) — 요청 머리글 `X-Presenter-Key`가 서버 환경변수 `MOM_PRESENTER_KEY`와 같을 때만 된다(서버에 키가 없으면 거절). **사건 복귀(`sim/recover`)는 최종용에서 막았다** (사건 버튼이 없어 복귀시킬 사건이 없음. 영상용에서는 그대로 쓸 수 있음).
**프로필 파일 `생성기/profiles/<이름>.json`**: `profile`(`name`, `clock`, `history_end`, `scripted_from`, `live_start`, `controls`), `run.out_dir`(`out_video`|`out_final`), `period`, `realtime`(`start`, `out_dir`, `rehearsal_script`, `live_days`), 날짜가 붙은 값(반복 알람 사례, 정비 기한, 충돌 구간, 확정 대기 일일 보고서 등). `db_target`은 **만들지 않음**(DB 쓰기는 서버 환경변수로 정함).
**환경변수**: `MOM_PROFILE`(video|final), `MOM_SIM_HOST`·`MOM_SIM_PORT`(도커에서만), `MOM_PRESENTER_KEY`, `MOM_PRETEND_NOW`(리허설용 가짜 현재 시각, 발표 때는 비움), 기존 `MOM_DB_RELAY_URL`·`MOM_INGEST_KEY`. (`MOM_ALLOW_SHARED_WRITE`는 DB 담당과 정한 뒤 추가.)
**DB 새 표 (제안, 아직 안 만듦)**: `demo_meta(profile PK, history_start, history_end, scripted_until, live_start, seed, generated_at)`, `live_owner(id=1 PK, owner, host, profile, last_beat)`.
**형식**: 날짜 `YYYY-MM-DD`, 시각 ISO 8601 `+09:00`(KST), 교대 시각 `HH:MM` 24시간, `shift_id`는 그대로(`YYYY-MM-DD-D|N`, 야간은 시작일 기준).

```powershell
cd <저장소 폴더>
```

- `-Profile`은 `-Screen`을 쓸 때 **필수**다. 없으면 멈춘다. 백엔드·비서만 켤 때는 필요 없다.

- `-LlmCompose`·`-NewChat`은 외부 Claude로 질문·문장이 나간다(가상 데이터만). 시험만 할 때는 빼도 된다.
