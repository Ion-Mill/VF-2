## 2. 채팅: 「이 화면 설명해 줘」는 정보판이 있는 화면에서만 (화면, 사용자 "진행해")

| 항목 | 내용 |
|---|---|
| 왜 | 화면 설명을 아직 안 붙인 화면에도 같은 버튼이 떠, 눌러도 정보판 글자가 없는 답이 된다 |
| 한 일 | `chips.ts`가 화면 이름을 받아, `line`(SCR-04)·`card`·`cards`(SCR-09)·`daily`(SCR-16)일 때만 `이 화면 설명해 줘`를 넣는다. 지침카드의 보전 말풍선에도 이 버튼을 넣었다(그 화면은 정보판이 있다). 그 밖 화면의 고정 말풍선에서는 뺀다 |
| 안 바꾼 것 | 채팅에 그 말을 직접 적는 길, 정보판 글자를 모으는 코드, 비서 답 규칙은 그대로 |
| 고친 파일 | `frontend/src/shell/chips.ts`·`Eve.tsx`, `frontend/tools/chips_check.mjs`, `UI설계서_최종본.md` (SCR-10 요소 2·개정 기록), `assistant/변경기록.md`, 이 파일, `파일설명.md` |
| 확인 | `node frontend/tools/chips_check.mjs`. 지금 켜진 화면(3000)이 이 가지가 아니면 브라우저에서 버튼을 못 본다 |
| 문서 담당(= 사용자)이 판단할 것 | UI설계서 SCR-10 요소 2의 "정보판 화면에서만" 문장과 보전 예시에 버튼을 넣은 것. 개정 기록 담당 칸은 이 표의 기존 형식(화면 담당)을 따름 |

## 3. 채팅: 어제 주간 교대 보고서 말풍선을 뺐다 (화면, 사용자 지시)

| 항목 | 내용 |
|---|---|
| 왜 | 카드를 안 연 작업자·반장 채팅의 선택 버튼 `어제 주간 교대 보고서 작성됐어?`를 빼기로 했다 |

| 문서 담당(= 사용자)이 판단할 것 | UI설계서 SCR-10 요소 2에서 그 버튼을 뺀 문장. 개정 기록 담당 칸은 이 표의 기존 형식(화면 담당)을 따름 |
