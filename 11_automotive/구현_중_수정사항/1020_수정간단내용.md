# 2026-10-20 수정 간단 내용

> 팀 전달 뒤 바뀐 내용을 핵심만 정리한다 (`CLAUDE.md` 규칙). 같은 날 수정은 이 파일에 더한다.

## 1. 시연 시계 [20:00으로] 넘기기가 거절되던 것을 고쳤다 (시연 서버가 읽는 생성기, 사용자 요청)

| 항목 | 내용 |
|---|---|
| 증상 | 17:00이 지난 휴무에 조작판 [20:00으로]를 누르면 `넘기기는 ['TODAY_17:00']만` 이 떴다. 화면(`SimPanel.tsx`)은 `TODAY_20:00`을 보내는데, `config.json`의 `skip_targets`와 `Realtime.skip`이 17:00만 알고 시각도 항상 17시로 잡았다 |
| 고침 | `skip_targets`에 `TODAY_20:00`을 넣고, `skip`이 그 이름이면 오늘 20:00(야간 교대 시작)까지 분을 만든다. 그 시각이 이미 지났으면 시계는 그대로. 17:00 넘기기와 다음 날 06:00 넘기기 금지는 그대로 |
| 확인 | 임시 측정 폴더로 시뮬레이터를 만들어 확인: `TODAY_17:00` → 2026-10-01 17:00, 이어서 `TODAY_20:00` → 20:00, 한 번 더 눌러도 20:00 그대로, `TODAY_06:00`은 거절. 시연 서버(8765)만 다시 켬. `생성기/out_realtime/cmm_drop` git 목록은 같음(시연 서버 측정 폴더는 `out_live`). 시계는 10/1 08:00부터 다시 흐름 |
| 문서 담당(= 사용자)이 판단할 것 | 없음. 화면이 이미 약속한 버튼이 서버에서 거절되던 것을 맞춘 것이다 |
