## 1. 시연 데이터 방식 바꾸기 (데이터·ML 담당 결정 — 문서 반영 완료, "확인" 칸 담당은 확인 필요)

| 구분 | 바뀌기 전 | 바뀐 뒤 |
|---|---|---|
| 과거 데이터 | 9/1~9/30 생성 → DB | 그대로 |
| 10/1 시연 데이터 | 사건 순서·시각 고정 (08:35 정비, 10:20 고장). 화면 숫자는 생성 뒤 맞춤 | **실시간으로 평탄하게 운영**. 발표자가 **사건 버튼**을 누르면 고장으로 이어질 데이터(축 부하, 공기 압력, 공구 사용량 등)가 서서히 또는 급격하게 바뀌어 알람이 뜸 |
| 진행 | 정해진 시각에 사건이 남 | 발표자가 원하는 때 버튼을 누름 (대기 지점 없음) |
| 시각·숫자 | 고정 | 고정하지 않음. 화면 계산 값을 그대로 씀 (문서 숫자는 **예시**) |
| 고장 범위 | — | **고장 난 설비만 멈춤.** 나머지 공정은 계속 돌고 재공이 쌓임 |

- **이유:** 시연의 중심은 AI 비서(먼저 알리기, 도움, 사내 문서 검색), 데이터 흐름, 쓰기 편한 화면이다. 데이터를 깊게 맞추는 것은 중심이 아니다.
- **꼭 같이 있어야 할 것:** 배속·일시정지 조절, 사건이 나면 자동으로 느려지기. 이게 없으면 1초 = 1분이라 AI 비서를 설명하는 사이에 수리가 끝나거나 교대가 끝난다.
