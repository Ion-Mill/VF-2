## 3. DB 중계를 공용 Supabase에도: "DB 1개 = 공장 1개" (백엔드·화면·생성기, 사용자 결정)

| 항목 | 내용 |
|---|---|
| 왜 | 팀은 Supabase(`mom-db`) 하나만 쓴다. 2장의 중계는 시연 모드(로컬 Docker DB)에서만 받아 Supabase에는 들어가지 않았다. 사용자 결정: **DB 1개 = 공장 1개** — 모두가 같은 DB·같은 데이터를 보고, 여러 명이 겹쳐 쓰는 것과 누가 [처음으로]를 눌러 모두의 10/1 기록이 지워지는 것은 받아들인다. 시계는 나중에 실제 시간으로 바꾼다 |
| 바꾼 것 | ① 백엔드 새 설정 **`MOM_SIM_SYNC=true`**: 중계 입구(`/api/ingest/sync`·`reset`·`clock`)만 연다. 시연 모드의 다른 문(로그인 없는 역할 토큰 등)은 열지 않는다. 시연 모드면 예전처럼 받는다 ② 중계의 "주소가 로컬이어야 함" 잠금을 없앴다 — 백엔드 스위치 하나로 정한다 ③ **기준점 확인**: 되돌릴 때 시뮬레이터 시작점(`Realtime.baseline()` = 10/1 08:00 + 표 11개의 마지막 번호)을 보낸다. 되돌린 DB의 시계·마지막 번호가 다르면 409 `BASELINE_MISMATCH`로 되돌리기를 취소하고 중계가 꺼진다 |
| 나중을 위한 설계 | 10/1 뒤 기록을 DB에 채우거나 실제 시간으로 바꿀 때: DB 기준점(`fn_demo_snapshot`)과 생성기 시작점을 **함께** 옮긴다. 하나만 옮기면 ③이 막는다(시뮬레이터 번호가 DB 줄을 덮어쓰지 않게). 실제 시간이 되면 시계 맞추기(`/api/ingest/clock`)를 끄고 DB 시계를 `REAL`로 두면 된다 — 줄 넣기(`sync`)는 그대로 쓴다 |
| 공용 DB 확인 (읽기만) | `mom-db` 기준점: 2026-10-15 찍음, 시각 10/01 08:00, 지금 DB와 알람·설비 상태·알림·작업지시서·문서 조각 수가 같고 9/30 일일 보고서도 둘 다 확정 전 → 지금 켜도 [처음으로]가 바르게 돌아간다. **채팅 기록(`chat_log`)은 지금 175건, 기준점 0건 → 처음 되돌릴 때(중계를 켠 시연 서버를 켤 때 포함) 채팅 기록이 모두 지워진다** |
| 켜는 법 | `frontend/README.md` "10/1 기록을 DB에도 넣기": `backend/.env.supabase`에 `MOM_SIM_SYNC=true` → 백엔드(8020) 다시 켜기 → 시연 서버 켜기 전 `MOM_DB_RELAY_URL=http://127.0.0.1:8020`·`MOM_INGEST_KEY`. 약속: **중계는 시연 진행자 한 명만** |
| 확인 | 로컬 Docker DB(10/23 다시 만든 최신 스키마) + 시연 모드 **끈** 백엔드(`MOM_SIM_SYNC=true`)로: ① 틀린 기준점 → 409, DB 시계가 그대로(되돌리기 취소) ② 진짜 시연 서버로 배속 180·S1 → DB에 알람 108·994·992, 작업지시서 초안 MW-1001(AI_DRAFT), 알림 ALARM_STOP·ALARM_WARN·REPEAT_ALARM·BOTTLENECK_MOVE·WIP_WARN·WO_DRAFT_READY·WO_APPROVAL_REQUEST, 중계 실패 0 ③ [처음으로] 뒤 10/1 줄·알림·작업지시서 0 ④ `pytest tools/tests` 104개, 생성기 `pytest` 11개, `check_queries.py` 231개 모두 PREPARE, `test_static_calls`는 전부터 있던 `maintenance.wo_cancel` 1건만 실패. 시험 뒤 로컬 DB는 기준점으로 되돌림 |
| 안 한 것 | 공용 `backend/.env.supabase`에 스위치 켜기, 공용 DB에 쓰기 — 사용자가 정한다. `.env.supabase.example`은 `MOM_SIM_SYNC=false`(설명 붙임) |
| 고친 파일 | `backend/app/config.py`(`sim_sync`)·`app/routers/ingest.py`(`_sim_only`, `reset` 기준점)·`app/services/sim_sync.py`(`check_baseline`)·`.env.example`·`.env.supabase.example`, `frontend/tools/db_relay.py`·`sim_server.py`(`_relay_base`)·`tools/tests/test_db_relay.py`(8개), `생성기/gen/realtime.py`(`baseline()`, `ID_TABLES`), `frontend/README.md`, `backend/docs/05_결정기록.md`(H-10)·`03_API_명세.md`, 이 파일, `파일설명.md` |

## 4. 화면 → 백엔드 전환 (C2): 화면이 백엔드 API만 부르는 길을 스위치로 더함 (화면·백엔드, 사용자 요청 "C2를 진행해줘")

| 항목 | 내용 |
|---|---|
