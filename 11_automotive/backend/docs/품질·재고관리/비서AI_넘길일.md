## 답하는 규칙

- 답에는 사내 문서 이름 + 번호 + § 출처를 붙입니다. 문서에 없으면 "문서에 없음"이라고 답합니다.

## 공통

- 범례·기호 뜻: ▲ 주의, 자물쇠 = 보류·확정 잠김, 점선 = 기록 없음, 공구 게이지 눈금 = 90% — UI설계서 2.1·2.3

## SCR-20 검사 기록

- 작업자(OPR)는 OP-50 태블릿 단계 화면을 씀: 측정 시작 확인 → CMM 측정 → 게이지·외관 → 다음 부품. 반장·관리자는 기존 화면. 캔버스의 [역할 바꿔 보기]에서 작업자를 고르면 태블릿 화면으로 바뀜
- 태블릿 "다음 부품"이 막힌 이유: M6·외관 입력 전, 외관 불합격이면 불량 코드 전, 다음 부품의 CMM 결과 전
- 검사 방식(초품·발췌·강화)이 뭔지, 강화 = 전수 + 항목 확대, 지금 왜 강화인지 (보류 — 정지 등급 알람 992 중 가공) — DOC-06 §3.1~§3.3
- OP-50 검사 시간: 평소 약 0.9분/개 → 강화 5.0분/개, 병목이 OP-50으로 옮긴 시각 11:20 (화면에서 뺌) — DOC-06 §3.4
- 강화 3단(위·중간·아래)이 뭔지 — DOC-06 §3.3. 판정에 쓰는지: DOC-06은 "기록만"으로 읽히지만 생성기 9월 데이터는 3단 모두 판정에 씀 → 백엔드는 생성기를 따름 (2026-10-14, 팀 확인 필요 — `../수정해야할 팀문서.md` 5-2)
- 측정 결과 자세히 (화면의 표를 뺌 — 값은 한눈에 보기 공차 막대·3D에 있음): 항목 번호(DOC-06 §2 1~8), 측정 위치, 측정기 CMM-01·측정자·측정 시각·받은 시각, 판정 플랫폼/측정기 둘 다, 입력 방식(자동/수동). 판정이 다르거나 수동이면 화면에 ▲로 보임 — DOC-06 §3.5
- 측정값이 들어오는 방법 (가정: 설비가 파일로 보냄): 측정기 CMM-01이 CSV 결과 파일을 공유 폴더에 쓰면 서버가 자동 기록, 부품 1개 = 파일 1개, 못 읽은 파일은 기록 안 하고 원본을 "오류" 칸에 보관 — DOC-06 §3.6. 파일로 오는 것은 3차원 측정기 항목뿐, M6 게이지·외관은 사람 버튼. 결과 파일 이름·줄 수 (화면에서 뺌)
- 측정 시작 확인: 로트 바코드를 찍어 측정 지시의 로트와 같은지 확인 (DOC-06 §3.6). 다르면 "다른 로트 — 부품 확인"
- M6 게이지 기준(통과 게이지 끝까지, 정지 게이지 2회전 넘게 안 들어감)·외관 기준(버·찍힘·뜯긴 면 없음) — DOC-06 §2 항목 6·7
- 재측정: 덮어쓰지 않고 반장이 판정에 쓸 값을 고름. 고르기 전엔 "확인 필요". 두 값 모두 상한 45.025를 넘으면 어느 쪽이든 불합격 — DOC-06 §3.5
- 수동 입력: "수동" 표시와 입력자가 남음. 반장 확인 전엔 로트 판정에 안 씀 — DOC-06 §3.5·§3.6
- 로트 판정 (칸을 한눈에 보기 머리로 합침): 모두 잰 뒤 판정, 불합격 1개면 보류 검토 + 남은 부품 전수. 판정까지 남은 시간 (남은 8개 × 5.0분 ≈ 40분). 불합격 순번 10·11 = DIM-01 치수 큼 (치명)
- 강화 끝내기 조건 2개 (원인 조치 완료 + 강화 로트 모두 합격 → 반장 [확인]). 강화 로트 = 보류 로트 041-1 + 다음 로트 041-2·042-1 (화면의 "강화 이유" 칸을 뺌) — DOC-06 §3.3
- Cpk 기준 (특별 특성 1.67 / 일반 1.33), 표본 = 최근 측정값 92개 (화면에서 뺌), 50개 미만이면 "계산 중 (n/50)", 미달이면 전수 측정 — DOC-06 §5.1·§5.2
- 관리도 = I-MR, 최근 30개 (화면에서 뺌). ±3σ 밖 1점 = 반장 주의 알림, 다음 부품 바로 측정. 공차 안이면 합격 그대로 — DOC-06 §5.3
- 측정 온도 조건 (부품 16~26 ℃) — DOC-06 §6
- 불량 등급 치명/중 (◆ 항목이면 치명), 파레토 누적 비율 (화면에서 뺌) — DOC-06 §8.1·§8.2
- 10:20 고장 때 VF2-01에서 가공 중이던 로트 = LOT-2609-041-1. 그때 몇 번 부품이었는지는 기록하지 않음 (부품별 설비 추적 안 함 — README "가정" 2절, FR-PRD-05-02 "부품마다 일련번호는 붙이지 않는다")
- 품질 이상 알림 (관리도 ±3σ 밖·불합격): **공정 단위**로 알림 — 예) "OP-30 정밀 가공 · 부싱 구멍 지름 관리 한계 밖". 어느 VF2에서 만든 부품인지, 원인은 알려 주지 않음. 검사 항목 → 공정: 1·2·4·5·6·8 = OP-30, 3 두께 = 미정, 7 외관 = 불량 코드별 (버 OP-40, 구성인선 OP-30, 찍힘·긁힘 운반·세척 중)
- "이 불량 어느 설비에서 났어?" → 부품 단위로는 모름. 이 로트를 가공한 OP-30 설비와 설비별 수량(공정 실적)까지만 답함
- 이 시안에는 LOT-2609-041-1 기록만 있음
- 한눈에 보기 읽는 법: 부품 지도 기호(✓ 합격 ✕ 불합격 ▲ 확인 필요·3σ 밖 ● 측정 중 — 기록 없음), 3D의 위·중간·아래 = 강화 3단 측정 위치, 공차 막대(파란 띠 = 공차, 점선 = 기준 치수, 빈 원 = 3단 값). 정상 값의 "상한까지 N" 여유 (화면에서 뺌)

## SCR-19 로트 추적

- 의심 로트 제안 (화면에서 뺌): 이 로트가 왜 의심 로트인지 (정지 등급 알람 992 중 가공), 제안 10:21 → 반장 보류 11:05. 제안만으로 상태가 바뀌지 않고 알림도 없음 — DOC-06 §4.2, FR-PRD-05-05
- 로트 상태 흐름 (화면에서 뺌): 생산 중 → 검사 대기 → 판정 대기 → 합격 / 보류 검토 / 보류 → 해제·폐기 → 출하됨. 보류·보류 검토·판정 대기·폐기는 출하 금지, 합격·해제만 출하 — DOC-06 §4.1·§4.3, FR-PRD-05-04
- 보류 사유와 누가 언제 보류했는지 (화면에서 뺌): 예) 정지 등급 알람 992 중 가공, 박○○ SUP 11:05
- 보류하면 생기는 일: 출하·다음 공정 이동 막힘, 재고 → 보류 수량, 이 로트 + 다음 1~2개 로트 검사 강화 — DOC-06 §4.1·§4.2
- 해제 조건 (전수 검사로 불량을 골라낸 뒤), 이미 출하한 로트는 보류 불가 — DOC-06 §4.1
- 권한: 보류·해제 SUP·MGR, 폐기 제안 SUP → 승인 MGR, OPR·MNT는 보기만
- 수량 (칸을 뺌 — 한눈에 보기 "수량"에 있음): 완료 = OP-50 양품 + 재작업 양품, 남은 = 합격 − 출하, 보류 수량은 따로
- 작업지시 자세히 (화면에서 뺌): 투입 수량, 납기, PO-2609-041 36개가 -1 20개 + -2 16개로 나뉜 이유 (원자재 로트가 바뀜)
- 공정별 자세한 기록 (화면에서 뺌): 원자재 재질·입고 검사 결과, 공정별 수량, 세척 묶음 수, 알람 연쇄 108 → 994 → 992. 작업자·설비별 수량(VF2-01 13개, VF2-02 7개)은 시간표 막대 설명에 있음 (어느 순번이 어느 설비인지는 기록 안 함)
- 검사 결과 자세히 (칸을 뺌 — 시간표 CMM-01 막대와 "수량"에 있음): 발췌 검사 방식 (첫 부품 + 5개마다, 나머지 육안 + M6 게이지 — DOC-06 §3.2), 초품 시각, 불합격 코드·등급 (DIM-01 치명)
- 관련 로트 (맨 위 로트 칸으로 옮김): 칩 옆 작은 글자 = 묶인 기준 (원자재·설비·교대·출하) — DOC-06 §4.2 순서 4. 점선 칩 = 이 시안에 기록이 없는 로트
- 완제품 입고 = 합격 판정 때 자동 — DOC-06 §4.3
- 출하한 로트가 나중에 의심 로트가 되면 출하 번호·출하처까지 보임 (고객 통보·회수는 범위 밖)
- 설비별 시간표 읽는 법: 파란 막대 = 고른 로트, 회색 막대 = 다른 로트, 막대 끝 점선 = 진행 중, 빨간 띠 = 고장, 빗금 = 정비, 주황 테두리 = 병목, 파란 세로선 = 지금, 검은 점선 = 보류. 막대에 마우스를 올리면 시각·작업자·수량. 시간 범위는 로트마다 자동 (가공 시작 ~ 지금 또는 출하)
- 고장 때 설비 안에 있던 로트 찾기: 빨간 띠와 겹치는 막대 (예: 10:20 VF2-01 → 041-1, VF2-01에서 13개 가공. 로트가 두 대에 나뉘어 있어도 로트 전체를 의심 로트로 봄) — DOC-06 §4.2

## SCR-21 재고

- 화면은 [재고] · [출하 등록] 두 탭. 출하 등록은 4단계: 로트 고르기(합격·해제 로트만 자동) → 수량 → 출하 전 확인 → 확정(확인 상자)
- "오늘 납기 전부 채우기" = 납기 10/1 로트를 남은 수량 전부로. 로트 카드 순서 = 먼저 합격한 순 (선입선출)
- 품목 표에서 뺀 것: 품목 번호 [가상] (TL-EM10 등), 단위, 관리 역할 (정비 소모품 6종 MNT / 공구·원자재·완제품 SUP) — UI설계서 SCR-21 [2]
- 거르기 (화면에서 뺌): "부족한 품목만", "공구만 보여 줘" 같은 질문에 비서가 목록으로 답함 — UI설계서 SCR-21 [1]
- 부족 기준 (재고 ≤ 안전 재고), 알림 받는 사람 (품목 관리 역할 + MGR) — FR-INV-01-07
- 안전 재고 식 = 설비에 달린 수 + 하루 사용량 × 3일분 [참고]. 완제품은 안전 재고·부족 알림 없음
- 차감 규칙 (화면에서 뺀 [5] 차감 규칙 보기) — FR-INV-01-03
  - 공구 교체 1회 = 1개 (페이스밀 인서트 5개)
  - 원자재 = 로트 투입 수량 (자동)
  - 절삭유 원액 = 보충 때 쓴 원액
  - 축 윤활유 = 매월 점검·보충 때
  - 주축 윤활유 = 매월 부은 양 (L)
  - 그리스 = 새 카트리지 1개
  - 필터 = 예방 정비 교체 때
  - 완제품 = 로트 합격 때 입고, 출하 확정 때 출고
- 거래 기록 자세히 (화면에서 뺌): 기록자, 조정 사유, 로트 투입에 쓴 원자재 로트 (MAT-2609-12·13), 원자재 입고 검사 결과
- 원자재 입고 검사: 입고 검사 대기 → 사용 가능 / 입고 보류, 성적서 대조, 사용 가능 전엔 투입 목록에 없음. 입고 시각 (화면에서 뺌) — DOC-06 §7
- 완제품 재고 = 합격 입고 합 − 출하 합 ± 조정 (음수 없음). 판정 대기·보류 검토·보류 수량은 재고에 안 넣음
- 출하 규칙: 합격(해제) 로트만, 선입선출이 아니면 사유, 부분 출하는 비고에 사유, 확정하면 잠기고 고치려면 사유 (수정 이력) — DOC-06 §4.3, DOC-01 §5.5
- 출하 로트별 작업지시 (화면에서 뺌 — 로트 번호 = 작업지시 번호 + 순번), 출하 일시 = 확정 시각 (보통 14:00). 출하 뒤 완제품 재고는 한눈에 보기 완제품 흐름에 있음
- 역할마다 버튼이 다른 이유: 입고·실사 = 품목 관리 역할 (MNT 정비 소모품 / SUP 공구·원자재·완제품), 출하 SUP, 공구 사용 기록 OPR (공구 수명 화면), 안전 재고 설정 MGR (설정 화면 SCR-25)
- 없는 기능: 구매·발주, 주문 접수·ERP 연동 (FR-INV-01-10), 차량·송장·포장 칸
- 드릴 Ø5.0 = M6 탭 아랫구멍용 — DOC-06 §2 항목 6
- 재고 여유 막대 읽는 법: 막대 = 지금 수량, 세로선 = 안전 재고, 막대 끝 = 안전 재고의 2배. 급한 품목이 위. 막대를 누르면 그 품목 거래 기록만 보임

## SCR-22 공구 수명
