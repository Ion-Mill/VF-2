### 3.1 교대 시작

**① 교대 시작 브리핑 확인 (SUP 전체, OPR 요약)** [가상: 기획서 AST-01]

| 브리핑 칸 | 확인할 것 |
|---|---|
| 지난 교대 요약 | 생산·불량·정지 횟수와 손실 수량 |
| 먼저 챙길 일 3가지 | 반복 알람, 재고 부족, 공구 수명 90% 이상 등 |
| 이번 교대 | 목표 90개, 작업지시·로트, 예방 정비 기한 |
| 출처 | 항목마다 붙은 기록 번호 링크를 눌러 원래 기록을 본다 |

- 브리핑은 문서가 아니라 화면이다. 미해결 알람, 24시간 넘게 처리 안 된 주의 알림, 승인 대기 문서가 위에 뜬다 [참고: 설계서 15.2].

**② 반장 시작 회의** [참고: NCS 작업계획수립 학습모듈 <표 3-4> 일상 점검표, PDF 48쪽 — "작업 개시 전: 정지 시 이상 체크, 설비 점검, 전일 작업 결과 보고, 금일 작업 계획·목표량 전달, 안전·품질 확인"]

| 3 | 이번 교대 목표(90개)와 작업지시 전달 | SUP |
| 4 | 안전·품질 주의 사항 전달 (보류 로트, 강화 검사 중인 로트 등) | SUP |

**③ 정지 사유 입력** [가상: 설계서 5.10, 기획서 13.2]

- 설비가 멈추면 **작업자(OPR)나 보전 담당자(MNT)가 정지 사유를 입력**하고, **반장(SUP)이 확정**한다.
- 알람으로 멈춘 정지는 알람 번호가 자동으로 붙는다. 알람 없이 멈춘 경우(소재 대기, 셋업 등)만 직접 고른다.

| 그룹 | 고르는 사유 (예) |
|---|---|
| 고장 (FAILURE) | 서보·앰프, 주축, 공구 교환장치, 윤활, 공압, 절삭유 |
| 자재·흐름 (MATERIALS) | 소재 대기, 앞 공정 대기, 뒤 공정 막힘 |
| 준비 (SETUP) | 로트 교체(작업지시 교체 셋업), 공구 교체, 초품 검사 |
| 조작 (OPERATION) | 프로그램 오류, 모드 오류, 도어 열림 |
| 계획 (PLANNED) | 예방 정비, 휴식, 계획 없음 |

### 3.3 교대 끝

**① 교대 보고서 확정 (SUP)** [가상: 기획서 PRD-02]

교대가 끝나면 비서가 **AI비서 초안**을 만든다. 숫자는 프로그램이 넣고, 비서는 "특이 사항"과 "인계 사항" 문장만 쓴다. **해당 교대 반장이 읽고 고쳐서 확정**한다.

| 칸 | 반장이 확인할 것 |
|---|---|
| 생산 | 목표 / 실적 / 불량 / 가동률이 화면 값과 같은지 |
| 로트 | 이 교대에 만든 로트, 완료·진행·보류 로트 |
| 정지 상위 3건 | 설비, 원인, 시간, 손실 수량 — 정지 사유가 모두 확정됐는지 |
| 병목 | 병목 공정·원인·시간, 속도 손실 수량 |
| 정비 | 작업지시서·작업기록서 번호, 알람, 조치 |
| 특이 사항 | 3~5문장. 사실과 다른 표현을 고친다 |

## 7. 공구 교체 (OP-30)

### 7.1 사용량 단위와 수명 한도

Haas 고급 공구 관리(ATM)는 공구 그룹마다 한도를 USAGE(사용 횟수), **HOLES(구멍 수)**, **FEED(이송 시간, 분)**, TOTAL TIME(총 시간)으로 정할 수 있다 [실제: Haas 매뉴얼 4.9.2, PDF 133~134쪽]. 우리 라인은 공구 종류마다 다른 단위를 쓴다 [가상: 설계서 5.13, 2026-10-05 결정].

| 공구 | 사용량 단위 | 부품 1개당 사용량 [가상] | 수명 한도 | 품목 번호 [가상] |
|---|---|---|---|---|
| M6 탭 (T05) | 구멍 수 (HOLES) | 4구멍 | 400구멍 (약 부품 100개) [참고] | TL-TAP6 |
| 드릴 Ø5.0 (M6 아랫구멍) (T04) | 구멍 수 | 4구멍 | 1,000구멍 (약 부품 250개) [가상] | TL-DR50 |
| 보링바 인서트 (Ø45 H7) (T03) | 구멍 수 | 1구멍 | 400구멍 (약 부품 400개) [가상] | TL-BB45 |
| 엔드밀 Ø10 (T02) | 이송 시간 (FEED, 분) | 2.5분 | 200분 (약 부품 80개) [참고] | TL-EM10 |
| 페이스밀 인서트 (T01) | 이송 시간 | 0.5분 | 400분 (약 부품 800개) [가상] | TL-FM50 |

- 공구 번호 T01~T05는 [가상]이다 (설계서 5.13). VF2-01·02가 같은 번호를 쓴다.

- 남은 수명 % = 1 − (누적 사용량 ÷ 한도). Haas ATM의 LIFE(잔여 수명 비율)와 같은 뜻 [실제: PDF 134쪽].

### 7.2 언제 바꾸나

| 때 | 표시 | 할 일 | 근거 |
|---|---|---|---|
| 사용량 **90%** | 화면 교체 알림, 교대 시작 브리핑 "공구 수명 90% 이상" | 이번 사이클이 끝난 뒤 또는 다음 셋업 때 교체 | [가상: 설계서 15.4] |
| 공구 만료 | 작업 표시등 **황색 점멸**, 공구 마모 경고 아이콘, 공구가 EXP 그룹으로 감 | 교체 | [실제: PDF 55쪽, 132쪽] |
| 알람 362 공구 수명 한계 도달 | 예비 공구가 없음 | 교체 → DOC-03 §2.13 | [실제: Haas 알람] |
| 알람 174 공구 부하가 초과됨 | 공구 부하 급증 | 공구 확인·교체 → DOC-03 §2.8 | [실제: Haas 알람] |

- 공구가 수명 80%를 넘으면 사이클 시간이 조금씩 늘 수 있다 [가상: 설계서 15.4]. 수명 90%를 넘긴 뒤 가공한 부품은 불량이 늘 수 있어 비서가 의심 로트로 제안할 수 있다 (5.4).

### 7.3 교체 순서 [가상: 순서 / 각 단계 근거는 오른쪽]

| # | 할 일 | 근거 |
|---|---|---|
| 1 | 가공 중인 사이클이 **끝난 뒤** 교체한다 (프로그램 중단 중 교체 금지) | [실제: PDF 165쪽 주의] |
| 2 | 화면에서 SETUP 시작 (정지 사유 "공구 교체", 3~8분) | [가상: 설계서 5.7] |
| 3 | 공구를 주축에 불러오고 [TOOL RELEASE](공구 배출)로 뺀다. 공구 교환장치에 직접 넣지 않는다 (항상 주축 → 공구 교환장치) | [실제: 4.11, PDF 138쪽] |
| 4 | 새 공구·인서트를 공구 홀더에 장착하고 홀더·풀 스터드 상태 확인, 테이퍼를 오일 적신 헝겊으로 닦는다 | [실제: PDF 132쪽] |

| 6 | **공구 오프셋을 다시 잰다** (4.3 ③) | [실제: 알람 362 설명 "툴 오프셋을 업데이트"] |
| 7 | **ATM 수명 리셋**: [CURRENT COMMANDS] → ATM 탭 → ALLOWED LIMITS 표에서 해당 그룹 강조 표시 → [F4]로 TOOL DATA → 만료 공구의 사용 계수기를 강조 표시 → [0] → [ENTER] | [실제: ATM 탭 위치·[F4]로 TOOL DATA 열기 = Haas 매뉴얼 4.9.2, PDF 133~134쪽 (영문 2025판 4.55, PDF 188·190쪽) / 사용 계수기 → [0] → [ENTER] = Haas 공식 알람 목록 362 설명(CSV 937행)] |

| 9 | SETUP 끝 → 다음 부품부터 양산 | [가상] |

- 7번 리셋 키 순서는 **Haas 공식 NGC 알람 목록의 알람 362 조치 문구**를 따른다 [실제]: "Reset the tool life in the Advanced Tool Management (ATM) tab. The tab is under the CURRENT COMMANDS tab. Highlight the usage counter for the expire tool, press [0] (zero), and then press [ENTER]." (한국어: "고급 공구 관리(ATM) 탭에서 공구 수명을 리셋하십시오 … 만료 도구의 사용 계수기를 강조 표시하고 [0](영)을 누른 다음 [ENTER]를 누릅니다"). 이 목록은 Haas 웹사이트 알람 검색(haascnc.com/service/alarm-search)의 2025-01-30 자료다. 조작 매뉴얼 본문(한국어판 4.9.2, 영문 2025판 4.55~4.56)에는 리셋 키 순서가 없다.
- 우리 라인의 ATM 그룹은 HOLES(구멍 수)나 FEED(이송 시간)로 한도를 정하므로, "사용 계수기"는 그 그룹이 쓰는 칸(HOLES 또는 FEED)의 누적 값이다 [가상: 해석]. 리셋 뒤 TOOL DATA의 LIFE가 100%로 돌아왔는지 본다.
- 참고: 알람 471(공구 **그룹** 수명 한계 도달) 설명에는 "공구 수명 화면에서 사용 횟수를 강조 표시하고 [ORIGIN]을 누름"이라는 다른 방법이 있다 [실제: 같은 알람 목록 471]. 우리 라인은 공구 1개를 바꿀 때 362 방법([0] → [ENTER])을 쓴다.
- 매크로 변수 #8001~#8200을 0으로 하면 해당 공구가 "사용 가능", 1이면 "만료"가 된다 [실제: PDF 136쪽]. 작업자는 쓰지 않는다 [가상].
- **ATM의 WARN 칸을 플랫폼 90% 알림과 맞춘다.** 모든 OP-30 공구 그룹의 WARN을 **10**으로 넣는다 [가상: 값]. 근거: WARN은 "제어장치가 경고 메시지를 보내기 전 그룹에 남아 있는 공구 수명의 최소값"이고, LIFE는 "공구의 잔여 수명 비율"이다 [실제: Haas 매뉴얼 PDF 134쪽, 영문 2025판 PDF 190쪽]. 플랫폼의 "공구 수명 90%"는 사용률이므로 남은 수명 10%와 같다 (DOC-07 9장). 그러면 제어기 화면의 **공구 수명(경고) 아이콘**과 플랫폼 교체 알림이 같은 때 뜬다 [실제: 아이콘 뜻 "남은 공구 수명이 설정 240 아래에 있거나 현재 공구가 해당 공구 그룹의 마지막 공구", PDF 111쪽].
- 설정 240(공구 수명 경고)은 매뉴얼 두 곳의 설명이 다르다. 아이콘 표(PDF 111쪽)는 "남은 공구 수명이 설정 240 아래", 설정 설명(PDF 446쪽, 영문 2025판 PDF 529쪽)은 "공구 마모가 한계 비율에 도달하면"이다 [실제]. 그래서 우리 라인은 그룹별 WARN 칸으로 맞추고, 설정 240은 바꾸지 않는다 [가상].
