# 테스트 질문 — 서버를 켠 뒤 화면 채팅(이브)에서 확인 (2026-10-25)

DB 담당·서버 배포 담당이 서버를 켠 뒤 **화면(`http://localhost:3000` 또는 배포 주소)의 이브 채팅**에서 아래 질문을 그대로 보내 본다. 비밀값이 없는 문서다.

## 질문

| 번호 | 질문 (그대로 입력) | 확인할 것 |
|---|---|---|
| 1 | `VF2-02 상태어떄` | VF2-02 **한 대**의 지금 상태가 나온다(가동·정지 같은 상태, 그 상태가 된 지 몇 분, 열린 알람이 있으면 알람 번호). 다른 설비 이야기나 "문서에 없음"으로 끝나면 불합격 |
| 2 | `모든 설비 상태는` | **설비 전체**의 지금 상태가 한 번에 나온다(한 대만 나오거나 알람 설명만 나오면 불합격). 설비 이름과 상태가 하나씩 보인다 |
| 3 | `병목 어디났어?` | **어느 공정이 병목인지**가 나온다(공정 이름과 이유). 알람 설명만 나오거나 "모름"이면 불합격 |

세 질문 모두 **숫자와 이름은 화면의 3D 라인 뷰·생산 화면과 비교**한다. 답에 나온 설비·공정이 화면과 다르면 어느 질문에서 다른지 적는다.

## 이렇게 확인한다
1. 서버를 켜고 화면을 연다. 로그인한 계정으로 이브 채팅 탭을 연다.
2. 위 질문을 한 개씩 보낸다. 한 질문에 답이 올 때까지(길면 수십 초) 기다린 뒤 다음 질문을 보낸다.
3. 각 질문의 답에서 아래를 본다.
   - 답이 오는가(오류·"응답 없음" 아님).
   - 위 표의 "확인할 것"과 맞는가.
   - 사내 문서에서 가져온 답이면 출처(문서 이름·절)가 붙는가.
4. 결과를 아래 형식으로 적는다.

| 번호 | 답이 왔나 | 확인할 것과 맞나 | 화면과 같나 | 메모(다르면 무엇이) |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

## 주의
- **질문을 보내면 기록이 남는다.** 공용 Supabase를 쓰는 최종용(final)에서는 공용 DB `chat_log`·`access_log`에 질문과 답이 저장된다(사용자별 30일). 또 질문과 사내 문서 조각이 외부 Claude로 나간다. 그러니 **위 3개만** 보내고, 반복해서 보내지 않는다.
- 권한 때문에 어떤 질문에는 "권한 밖" 답이 나올 수 있다. 값 없이 누가 볼 수 있는지만 알려 주는 정상 동작이다.
- 답이 문서에서 온 것인지(출처 표시), 운영 데이터에서 온 것인지는 서버 설정(`DOCS_SOURCE`, 어느 DB)에 따라 다르다. 이 세 질문은 설비·생산 **운영 데이터**를 묻는 것이라 DB 연결(`final` = Supabase, `video` = 로컬 DB)을 확인하는 데 쓴다.
- 이 파일은 "무엇을 물을지"만 정한다. 기대하는 정확한 숫자는 켜는 시점의 데이터에 따라 달라서 적지 않았다.
