2.2 Tool Holder and Pull Stud Information

Introduction

Examine tools, toolholders, and pull studs regularly. Replace toolholders and pull studs with surface damage.

RPMs higher than 10,000 must have balanced tooling of grade G2.5 or lower (ISO 1940 and ANSI S2.19).

Oversize Tools: In the POCKET TOOL TABLE, you must choose L-LARGE TOOL & ASSUMED HEAVY for tools with the diameter greater than diameter E (some decals use the value of C, or a specific value above the  max tool diameter) which can be found on the tooling decal.

  • An extra tool change can occur when the tool changer stores tools with the "Large" designation. The tool changer arm moves down a certain distance during a tool change. 
  • NOTE: Please reference your specific machines layout drawing for the double arm drop down distance, please reference the following step on where to access this information. 

Caution: Do not use tools that have these problems:

  • Incorrect taper size
  • Incorrect pull stud size or type
  • Damaged tool taper
  • Debris between the tool taper and the spindle taper

Tools with these problems can cause damage to the spindle.

 Caution: Do not use the spindle to tighten tools.

To access the double arm drop down distance first, go to the machine drop down on the Haas main page [1] select your machine model, press "Learn More" and under the "Technical Document" section the layout drawing should be accessible [2].  This measurement [3] is found within these drawings and varies between machine lines and taper size.

Max Speed Decal provides information on the Max Spindle Speed based on tool Diameter and Length.

Do not exceed the Max Spindle Speed.

2.3 Spindle Drawbar - Force

Introduction

This reference document shows the recommended spindle drawbar force values for 20T, 30T, 40T, 50T & HSK spindles. A low spindle drawbar force results in significant clamp force loss typically caused by a crack or break in the belleville spring washer. To check the drawbar force, follow the Spindle - Drawbar - Force Measurement - VMC procedure.

 Note:  A loss of ~ 50% of nominal clamp force is an indication of this failure mode.

Note: As a drawbar wears in during normal use a slight decrease in clamp force is expected.  This is not an indication of drawbar failure.

Note: The 09-xxxx part numbers listed for the 40T and 50T spindles are the Spindle Drawbar Force Gauge Tool available through E-Commerce.

Refer to the Spindle - Drawbar - Troubleshooting Guide
