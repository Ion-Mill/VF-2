## Alarm Search Results:**174****TOOL LOAD EXCEEDED**

---

Tool load during a feed exceeded the user-defined tool load limit. Do these steps before continuing: Make sure that the tool load limit is set correctly on the Advanced Tool Management (ATM) tab. This tab is under CURRENT COMMANDS. Inspect the tool for wear. Replace it if necessary. Check the program for errors and for appropriate speeds and feeds. Reset the tool load limt for the tool in the spindle, if necessary. Reset the alarm and resume the program.
