# AI 운영 비서 기반 자동차 부품 절삭가공 라인 운영 관리 플랫폼 (MOM)

> 설비와 생산을 지켜보다가 문제가 생기면 **"무엇이 문제인지 → 생산에 어떤 영향이 있는지 → 어떻게 안전하게 조치하는지"** 를 근거와 함께 먼저 알려 주고, 작업지시서·작업기록서·교대 보고서·일일 보고서의 **초안까지 써 주는** AI 운영 비서 "이브"를 만든 5인 팀 프로젝트입니다. **초안은 AI가, 확정은 사람이** 합니다.

- 기간: 2026-10-12 ~ 10-23 (개발 2주), 발표 10-26
- 형태: 5인 팀 (기획·데이터·사내 문서·화면·서버·DB·배포·AI 비서를 나눠 개발)
- 모든 운영 데이터는 **가상**입니다. 알람 번호와 안전 절차 같은 문서 내용은 실제 공개 자료를 바탕으로 했고, 운영 기록은 실제 공개 기록의 모양을 따라 만들었습니다.

## 무엇을 하는 시스템인가

가상의 자동차 부품 협력사 한 곳(엔진 마운트 브래킷 1종, 5공정, 주·야 2교대, 설비 6대)의 가공 라인을 대상으로 합니다.

| 기능 | 설명 |
|---|---|
| 3D 라인 모니터링 | 실제 치수로 그린 라인에 설비 상태·재공·병목이 데이터 값 그대로 나옵니다. 보기만 하고 설비 조작은 없습니다(안전 원칙) |
| 알람 → 지침카드 | 알람이 뜨면 원인·먼저 할 일·안전 절차·생산 영향(손실 수량, 목표 미달 예측)을 한국어 카드로 보여 줍니다 |
| 문서 흐름 | 지침카드 → 작업지시서(AI 초안, 보전 수정, 반장 승인) → 작업기록서(보전 확정) → 교대 보고서 → 일일 보고서 |
| 먼저 알리기 | 문제를 프로그램이 전부 모아 정해진 순위로 정렬하고, 긴급·주의·문서 알림을 구분해 전달합니다 |
| AI 비서 채팅 | 사내 문서 검색(RAG)과 읽기 전용 조회 도구 14개로 답하고, 출처(문서·절)를 붙이며 없으면 "문서에 없음"이라고 답합니다. 음성 입력도 됩니다 |
| 역할별 화면·권한 | 현장 작업자·보전 담당·라인 반장·공장 관리자의 화면과 권한이 다릅니다 |
| 시연 프로그램 | 가상 데이터 생성기가 공장 역할을 하며 실시간 값을 만들고, 배속·일시정지·사건 버튼으로 시나리오를 재현합니다 |

## 설계에서 지킨 원칙

1. **근거 없으면 답하지 않는다**: 답마다 사내 문서 이름·번호·절 출처를 붙입니다.
2. **계산은 코드가, 문장은 AI가**: 손실 수량·예측·보고 순서는 프로그램이 정하고 AI는 문장으로만 옮깁니다.
3. **안전 절차는 AI가 쓰지 않는다**: 잠금·표지·보호구는 고정 서식을 그대로 붙입니다.
4. **AI는 초안만, 확정은 사람이**: 승인·보류·출하·설비 조작은 사람만 합니다. 비서는 읽기 전용 DB 계정과 정해진 조회 도구만 씁니다.
5. **권한은 3겹**: 서버가 역할별로 주소를 막고, 내 것·담당 범위를 확인하고, 중요한 일은 DB 함수가 한 번 더 막습니다.

## 기술

| 영역 | 사용한 것 |
|---|---|
| 화면 | Next.js 14, React 18, TypeScript, three.js(3D), Tailwind CSS |
| 서버 | Python FastAPI, SQLAlchemy 2, psycopg 3 (API 168개) |
| DB | PostgreSQL 16 (테이블 72개, 업무 규칙은 트리거·함수·제약), 운영은 Supabase |
| 실시간 | SSE(`LISTEN/NOTIFY`) 채널, 화면은 1초·4초 폴링 |
| AI 비서 | Anthropic API(Claude Haiku), 호출 실패 때만 Gemini 대체, BM25 + 한국어 2-gram 문서 검색, 음성 입력 faster-whisper |
| 데이터 | Python 가상 데이터 생성기(같은 seed면 같은 결과) |
| 배포 | Docker Compose 컨테이너 5개(caddy·web·sim·backend·assistant), AWS EC2 한 대 |

## 검증한 것과 한계

| 구분 | 내용 |
|---|---|
| 검증 | 문서 근거 답변 정답 절 인용 73/75, 문서에 없는 질문에 지어내지 않는지, 안전 문구 누락 여부, DB 시험 47/47, 주소 전부를 3개 역할로 호출 129건 서버 오류 0, 동시 접속 100명 응답 중앙값 0.5초 (2026-10-25 기록 기준) |
| 한계 | 운영 데이터가 가상이라 현장 효과(정지 시간 감소 등)는 측정하지 못했습니다. 프롬프트 인젝션 전용 테스트와 공장 소음 속 음성 입력은 시험하지 못했습니다. 서버는 한 대(이중화 없음)입니다. 선조치 기록 일부(기록 없는 정지 목록, 사진, 반장 확인)는 설계서에만 있고 백엔드는 아직 만들지 않았습니다 |
| 실제 라인에 붙이려면 | 생성기 자리에 실제 설비 데이터(PLC·MTConnect 수집)를 같은 형식으로 연결하고, 사내 문서를 실제 작업 표준으로 바꾸고, 서버 이중화·모니터링을 더합니다 |
